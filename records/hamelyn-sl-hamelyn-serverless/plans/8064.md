# Coding Plan for hamelyn-sl/hamelyn-serverless#8064: El cupón falla en checkout para carritos anónimos recién creados

Source report: [records/hamelyn-sl-hamelyn-serverless/items/8064.md](records/hamelyn-sl-hamelyn-serverless/items/8064.md)

## Summary

El defecto sigue presente en `dev`: el primer alta optimista de un carrito anónimo guarda un `cartId`, pero crea el estado local con otro ObjectId. Checkout valida el cupón usando ese segundo ID y el endpoint devuelve `invalidCartError`.

## Plan

Corrige el flujo de carrito anónimo recién creado: en `CartContext`, evita crear un `_id` optimista distinto del `cartId` persistido; si el POST devuelve un `cartId` canónico, reconcílialo en estado y `localStorage`. Añade la traducción `coupon.errors.invalidCartError` a los locales de checkout y cobertura versionada para aplicar cupón antes de recargar. No modifiques el contrato de capabilities, la autorización de carrito ni `CHANGELOG.md`. Contexto relacionado: https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7923.
