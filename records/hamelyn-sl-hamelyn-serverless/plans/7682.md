## Summary

Este PR sigue siendo necesario, pero no está listo para fusionarse: deja los proyectos nativos versionados y el runtime de OTA desalineados con Expo SDK 57, por lo que una build de EAS o una actualización publicada puede mezclar artefactos nativos incompatibles.

## Plan

Corrige la migración de Expo SDK 57 de Supply en la rama de este PR. Regenera `apps/supply/ios` y `apps/supply/android` mediante Expo prebuild desde la configuración declarativa, sin editar manualmente archivos nativos, y versiona únicamente las salidas generadas necesarias para alinear Expo 57 y Android SDK 36. Cambia `runtimeVersion` para que las OTA de la nueva build no se entreguen a binarios anteriores; conserva los canales EAS existentes salvo que la configuración requiera un ajuste mínimo. No añadas ni modifiques `CHANGELOG.md`, no cambies funcionalidades de Supply y no introduzcas dependencias fuera de la matriz Expo 57. Después ejecuta los checks de Supply, prebuild limpio para iOS y Android, y prepara evidencia para que el autor valide instalación, arranque y OTA con datos privados redactados.
