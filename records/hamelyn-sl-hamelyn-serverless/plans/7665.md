## Plan

Repara la PR https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7665 sin ampliar su alcance. Añade a los dos issue watchers un gate de producción default-off o un marcador de bootstrap que impida cualquier dispatch/write hasta que el estado 28 + 6 esté importado y validado; los dry-runs manuales deben seguir funcionando en namespace separado. Haz que el precheck aborte el run si no puede leer los comentarios de una canónica, sin convertir el error en `[]`, y usa `issue.created_at` como fallback cuando no existan timestamps previos del watcher. Añade regresiones para despliegue con store vacío, fallo HTTP de comentarios y canónica reciente sin timestamps. Integra `dev` mediante merge, conservando los tests de proof actuales de `apps/agents/package.json` y el cron `40 8 * * *` de `apps/agents/vercel.json`. No versiones el importador one-time, no edites `CHANGELOG.md`, no cambies el contrato de los heartbeats ni las automatizaciones de Paperclip, y mantén las operaciones GitHub sin asignaciones ni apertura de PRs.
