## Summary

## What This Changes

El PR valida divergencias `MK_ONLY` y `DB_ONLY` contra la API viva de MercadoLibre, muta los estados internos según el resultado y añade un `workflow_dispatch` con dry-run.

## Best Possible Solution

Validar el payload multiget con Zod, clasificar únicamente un `404` explícito como `not_found`, reintentar códigos individuales transitorios y conservar `fetch_error` como no-op; después, ejecutar `dry_run=true` antes del merge y adjuntar logs redacted.
