## What This Changes

La issue solicita sustituir las actualizaciones npm de versión de Dependabot por un updater semanal y manual que actualice conjuntamente el workspace pnpm en un único PR contra `dev`.

## Best Possible Solution

Mantener un único PR semanal generado con Node 24, limitar el PAT exclusivamente a los pasos de escritura, reconciliar la rama sin perder arreglos existentes y demostrar mediante un `workflow_dispatch` redactado la actualización minor/patch, el rechazo de majors y la creación o actualización del PR.
