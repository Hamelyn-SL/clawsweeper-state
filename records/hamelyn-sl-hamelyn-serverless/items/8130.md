## Label Justifications

- `P1`: El checkout puede añadir un coste inesperado en una tienda activa pese a una propuesta comercial visible.
- `impact:ux-friction`: El usuario descubre una diferencia entre el mensaje de envío gratuito y el importe final del pedido.

## Summary

Gracias por el reporte: la lógica de EE. UU. busca absorber el envío en el precio, pero la configuración actual permite que el checkout cobre un resto; esta incidencia sigue siendo necesaria.

## What This Changes

La incidencia informa de que us.hamelyn.com muestra una propuesta de envío gratuito, pero durante la compra se aplica un coste de envío.

## Best Possible Solution

Fijar un suplemento de EE. UU. que cubra las tarifas estándar reales y añadir una prueba de checkout que garantice coste estándar cero para la configuración vigente.
