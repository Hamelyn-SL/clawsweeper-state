## Summary

La incidencia sigue siendo necesaria: el código actual reproduce el refresco Mongo en cada reutilización warm y una PR abierta vinculada propone el arreglo, pero aún debe resolver con seguridad el enriquecimiento de usuarios de Analytics Supply.

## What This Changes

Evitar tormentas de reconexión al refrescar configuración Mongo y desacoplar de forma segura la ruta de analítica de Supply.

## Best Possible Solution

Mantener el pool sano mediante TTL, single-flight y stale-on-error, y preservar temporalmente `mongo_user_id` hasta que exista un enriquecimiento asíncrono o se apruebe su retirada.
