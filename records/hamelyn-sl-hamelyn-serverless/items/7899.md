## Summary

Se mantiene abierto: el head incumple la aceptación para primeras visitas sin cookie y puede bloquear el alta de más variantes desde Admin.

## What This Changes

El PR convierte la promo strip fija en una configuración multilingüe de Admin persistida en Vercel KV, con variantes asignadas en servidor por visitante.

## Best Possible Solution

Mantener el fallback i18n, asignar variantes solo después de recibir una cookie previa y dejar el estado del botón enteramente bajo control de React antes de validar el flujo real Admin→KV→Ecommerce.
