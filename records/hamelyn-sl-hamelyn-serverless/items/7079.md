## Summary

## What This Changes

The issue asks to unify the pages-router and app-router request authorizers so read-only roles cannot perform writes, and to update the corresponding buying/account BL spec.

## Best Possible Solution

Land a narrow reviewed authorization fix that routes both wrappers through one shared core, denies non-GET/HEAD requests for users whose roles are all read-only, preserves existing admin/ATC behavior, and adds the renumbered BL spec plus focused regression coverage.
