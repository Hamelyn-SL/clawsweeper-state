## Summary

La issue sigue siendo necesaria: `dev` mantiene `Pillow==10.4.0`, la ruta vulnerable procesa bytes externos sin restringir formatos y no hay un PR abierto que implemente la corrección. Conviene coordinarla con las dos alertas relacionadas para aterrizar un único bump a `12.2.0` o posterior.

## What This Changes

La issue solicita actualizar Pillow para corregir una escritura fuera de límites alcanzable al decodificar imágenes PSD en una migración manual.

## Best Possible Solution

Actualizar el pin compartido a `Pillow==12.2.0` o una versión posterior compatible, y validar `analyze_image`, `convert_to_webp` y `get_image_embedding` con imágenes de prueba antes de volver a ejecutar la migración sobre datos reales.
