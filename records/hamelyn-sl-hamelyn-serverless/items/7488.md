## What This Changes

La issue solicita generar y publicar automáticamente evidencia de cada PR mediante un router que elija entre GIF agéntico, proof card o barrera documentada ejecutados en Vercel Sandbox.

## Best Possible Solution

Construir un piloto manual `/proof` por entregables: controlador externo con contrato Zod y credenciales de publicación, snapshot versionado, proof card más barrera y, después, GIF agéntico; cada artefacto debe quedar ligado al SHA y publicarse solo tras revalidarlo.

- El checkout de un PR no confiable podría exfiltrar o utilizar credenciales si el token de publicación o las claves del modelo se introducen directamente en la microVM.
