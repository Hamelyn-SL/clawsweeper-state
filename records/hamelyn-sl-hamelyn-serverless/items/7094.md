## Summary

Mantener abierta: `dev` sigue descartando `state` y `province` en direcciones `DE`/`FR` antes de guardarlas, mientras la validación F2 documentada exige conservar el valor recibido cuando exista. ## What This Changes

Corregir `resolveAddressProvince` para que las direcciones de Alemania y Francia conserven `state` o `province` recibidos, dejando la provincia vacía únicamente si no llega ninguno de ambos valores.

## Best Possible Solution

Ajustar la función aislada para que en `DE`/`FR` use `state || province` sin fallback a `locality`, actualizar los casos BL y la spec para reflejar el contrato F2, y dejar fuera de este arreglo cualquier backfill histórico.
