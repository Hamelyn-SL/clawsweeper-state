## Label Justifications

- `P2`: Es un bug acotado de lógica de negocio en la normalización de direcciones de perfil, con impacto real pero limitado a países concretos.
- `impact:data-loss`: Un valor de provincia o estado proporcionado por el vendedor se descarta silenciosamente para direcciones de Alemania y Francia.

## Summary

Mantener abierto: en `dev` la normalización de direcciones sigue vaciando la provincia para `DE`/`FR` aunque el vendedor envíe `state` o `province`, y la PR de BL ya mergeada documentó la divergencia en lugar de corregirla.

## What This Changes

El issue pide que las direcciones de perfil de Alemania y Francia conserven `state || province` cuando se proporciona y dejen la provincia vacía solo cuando no llega ningún valor.

## Best Possible Solution

Cambiar `resolveAddressProvince` para que en `DE`/`FR` devuelva `state || province || ""`, manteniendo el fallback a `locality` solo para países no opcionales, y actualizar la spec y los tests de `BL-buying-account-11` en el mismo PR.
