## Label Justifications

- `P1`: La exclusión silenciosa del despliegue dejó producción con una política de tokens antigua y bloqueó el login del CLI afectado.
- `impact:auth-provider`: La incidencia afectó a la emisión de tokens y a los scopes requeridos por usuarios con rol `cli`.
- `impact:other`: El problema central es la automatización de despliegues de una aplicación gestionada por GitHub Actions.

## Summary

La incidencia sigue siendo necesaria: el despliegue gestionado por GitHub Actions no selecciona ni invoca `hamelyn-api`, mientras Vercel mantiene desactivados los despliegues Git directos.

## What This Changes

Añadir `API` al pipeline de despliegue, enrutar cambios de `apps/api` y de runtime compartido, y documentar y verificar los hooks de Vercel.

## Best Possible Solution

Mantener Vercel Git desactivado y completar el pipeline explícito con hooks de API, selección por cambios y una comprobación dirigida en `dev` y `master`.
