## Label Justifications

- `P1`: Una versión de API sin desplegar ya bloqueó la creación de tokens del CLI para usuarios reales.
- `impact:auth-provider`: El incidente afecta a políticas de scopes y a la emisión de tokens de autenticación.

## Summary

La incidencia sigue siendo necesaria: `apps/api` permanece fuera del selector manual, los hooks del workflow y las rutas por cambios de código compartido; no existe una PR canónica que la resuelva.

## What This Changes

Añadir `API` al despliegue explícito de GitHub Actions, incluidos sus hooks, el cálculo de proyectos afectados y la documentación operativa.

## Best Possible Solution

Provisionar ambos deploy hooks y añadir API al orquestador existente, con cobertura del enrutado para cambios de API, raíz y `packages/core`, manteniendo Vercel sin despliegues Git.
