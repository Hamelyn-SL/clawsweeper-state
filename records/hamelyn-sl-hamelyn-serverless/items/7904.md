## Summary

La incidencia sigue siendo necesaria: la configuración actual desactiva los despliegues Git de Vercel y el pipeline de GitHub Actions no conoce ningún target `API` ni sus hooks.

## What This Changes

Añadir `apps/api` al pipeline explícito de despliegue desde `dev` y `master`, incluyendo hooks, detección de cambios compartidos, cobertura y documentación.

## Best Possible Solution

Incorporar `API` como destino gestionado, activar sus hooks en el workflow y cubrir el cálculo de rutas para `apps/api`, `packages/core` y ficheros raíz de runtime, sin reactivar Git deployments de Vercel.
