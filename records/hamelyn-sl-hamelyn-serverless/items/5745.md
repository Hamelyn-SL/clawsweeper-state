## Summary

Conviene mantener abierta esta incidencia: la corrección fusionada el 15 de julio de 2026 eliminó los bypass conocidos, pero el watcher volvió a observar 429 el 16 de julio y el código todavía coordina la cuota únicamente dentro de cada proceso. Aún falta determinar si esos eventos se recuperan siempre o vuelven a causar pérdida parcial de ASINs.

## What This Changes

Corregir el throttling 429 de Amazon Catalog API durante la resolución de ASINs y evitar que los chunks agotados queden ocultos como una ejecución satisfactoria.

## Best Possible Solution

Conservar la mitigación fusionada y medir una ventana completa de siete días; si reaparece un error terminal correlacionado con ASINs perdidos, coordinar la cuota entre instancias, respetar `Retry-After` con jitter y devolver los chunks agotados como fallo parcial explícito y observable.
