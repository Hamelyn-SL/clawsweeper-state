The issue requests splitting generic picking and packing productivity measurements into operational subtypes for more useful warehouse performance reporting.

## Best Possible Solution

Adopt a product-approved subtype model, likely `metadata.operationSubtype` plus derived fallbacks for historical records, while keeping generic `operationType` values unless maintainers explicitly want new enum values and migration work.
