## Summary

La PR aborda una carrera real de START, pero permanece como borrador y necesita prueba observable del flujo con el índice activo antes de poder fusionarse. También requiere confirmar la operación manual de Atlas que sostiene la garantía de unicidad.

## Best Possible Solution

Fusionar después de demostrar el flujo concurrente con el índice ya creado y de dejar un responsable y una comprobación post-despliegue para la transición de sesiones heredadas.
