## Summary

La issue sigue siendo necesaria: el handler ya devuelve un resumen estructurado, pero conserva HTTP 200 para todo rechazo parcial y no define la severidad ni una señal operativa común solicitadas.

## What This Changes

Definir un contrato compatible de severidad, respuesta y observabilidad para rechazos parciales de los cron compartidos.

## Best Possible Solution

Conservar temporalmente la compatibilidad HTTP y acordar un resumen estructurado común; después aplicar estados o alertas por ruta según una matriz de severidad documentada.
