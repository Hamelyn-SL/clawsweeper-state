## Summary

La incidencia sigue vigente en `dev` y una PR abierta vinculada concentra la reparación; debe permanecer abierta hasta que esa PR se revise e integre.

## What This Changes

Corregir las tarjetas raíz de PR en Slack para que reflejen el reviewer asignado, se actualicen tras cambios y puedan repararse mediante `workflow_dispatch`.

## Best Possible Solution

Integrar la PR vinculada tras su revisión y comprobar en producción un refresh real de Slack y KV; entonces GitHub podrá cerrar esta incidencia por la referencia de cierre.
