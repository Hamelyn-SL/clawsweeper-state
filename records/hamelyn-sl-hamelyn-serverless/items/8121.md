## Summary

La incidencia sigue vigente en `dev` y ya tiene una PR abierta que concentra la corrección; cerrarla antes de integrar esa reparación sería prematuro.

## What This Changes

Corregir las tarjetas raíz de PR en Slack para que muestren el reviewer real, se refresquen tras reasignaciones y puedan repararse mediante `workflow_dispatch`.

## Best Possible Solution

Integrar la PR vinculada tras su revisión y comprobar un evento real de asignación o review para confirmar que la tarjeta existente se actualiza sin duplicarse.
