## Label Justifications

- `P1`: El flujo de notificaciones de PR omite la mención al reviewer real y obliga a verificar GitHub manualmente.
- `impact:message-loss`: Las menciones de Slack dirigidas a reviewers se suprimen cuando la solicitud de revisión ya fue consumida.

## Summary

La incidencia sigue vigente en `dev`: la tarjeta raíz sólo lee solicitudes de review actuales y el workflow no escucha cambios de reviewer. La PR abierta vinculada concentra la reparación, por lo que cerrar ahora o duplicar el trabajo sería prematuro.

## What This Changes

Corregir las tarjetas de PR en Slack para que muestren y refresquen el reviewer real, incluidos los casos de fallback y reparación manual.

## Best Possible Solution

Integrar una reparación que refresque la tarjeta existente con el reviewer efectivo y permita reconstruir mensajes antiguos sin duplicar raíces.
