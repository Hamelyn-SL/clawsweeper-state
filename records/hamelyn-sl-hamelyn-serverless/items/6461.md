## Label Justifications

- `P2`: La gestión de cupones funciona actualmente y el trabajo restante es una mejora normal y acotada de UX interna.

## Summary

La petición sigue siendo necesaria: `dev` ya ofrece un formulario compacto, responsive, dividido en secciones y con campos condicionales, pero todavía carece del flujo por pasos, selector visual, vista previa y duplicado pre-rellenado solicitados. Debe mantenerse como seguimiento canónico frente a https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7548, aunque antes de implementar conviene decidir si la separación entre descripción interna y texto de checkout pertenece a esta entrega.

## What This Changes

Rediseñar la creación y edición de cupones en Admin como un flujo guiado, responsive y reutilizable, con campos contextuales, vista previa y duplicado pre-rellenado.

## Best Possible Solution

Mantener esta issue como única especificación del rediseño y construir un componente guiado reutilizable para crear, editar y duplicar sobre el contrato actual; si producto aprueba dos textos distintos, añadir después un campo compatible de extremo a extremo con migración y fallback para cupones existentes.
