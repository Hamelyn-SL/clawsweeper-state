## Summary

Gracias por el contexto: la mejora sigue siendo necesaria; `dev` solo evita el gate pesado en cambios documentales y aún ejecuta lint, typegen, typecheck y las suites de core/API para cualquier cambio de código.

## What This Changes

Optimizar el gate de CI para ejecutar lint, typegen, typecheck y suites de tests únicamente en los workspaces afectados, conservando un fallback completo y fail-open para cambios globales o detección fallida.

## Best Possible Solution

Añadir una selección de workspaces afectados con Turbo para el flujo de PR, conservar el gate completo para cambios globales o errores de cálculo y dejar el modo completo actual como ruta compatible para los consumidores compartidos del script.

## Repair Work Prompt

Implementa el scoping del gate de CI por workspaces afectados para esta issue. Mantén siempre el required check `Lint and typecheck`; para PRs de código calcula de forma fiable el grafo afectado, ejecuta lint/typegen/tsc solo donde corresponda y condiciona las suites BL/registry/API/OpenAPI según alcancen `@hamelyn/core` o `api`. Cualquier cambio global (lockfile, tsconfig base, `@hamelyn/code-config`, `turbo.json`, `scripts/ci-checks.sh` o workflows) y cualquier error de cálculo debe ejecutar el gate completo. Conserva `bash scripts/ci-checks.sh` sin argumentos como ejecución completa para `dependency-update-autofix` y el skill de Dependabot; si añades scoping, debe ser opt-in o inequívocamente exclusivo del workflow de PR. No modifiques `CHANGELOG.md` salvo requisito explícito. Añade pruebas o comprobaciones locales no versionadas para los casos admin, core, archivo global y detección fallida.
