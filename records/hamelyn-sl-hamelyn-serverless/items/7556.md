## Summary

Gracias por el contexto: la mejora sigue siendo necesaria. En `dev`, cualquier cambio de código continúa ejecutando lint, typegen, typecheck y todas las suites; no hay PR abierta que implemente la selección por workspaces.

## What This Changes

La incidencia solicita que el gate de CI ejecute lint, typecheck y suites solo para los workspaces afectados, conservando el check requerido y un fallback completo.

## Best Possible Solution

Centralizar el cálculo del grafo afectado, aplicar ese alcance a typegen, `tsc` y suites, y mantener el modo global sin argumentos para consumidores compartidos.
