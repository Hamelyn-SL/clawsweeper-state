## Summary

Gracias por el contexto: la mejora sigue siendo necesaria. El CI actual solo distingue cambios docs-only; cualquier cambio de código continúa ejecutando las comprobaciones y suites globales.

## What This Changes

La issue solicita que el gate de CI calcule los workspaces afectados y ejecute únicamente sus comprobaciones, con fallback seguro al ciclo completo.

## Best Possible Solution

Centralizar la resolución del grafo afectado, limitar typegen, typecheck y suites a ese grafo, y conservar el gate completo ante errores o cambios globales.
