## Label Justifications

- `P2`: Es una mejora planificable con ahorro recurrente de runner y feedback más rápido, pero no corrige una regresión urgente de producto.
- `impact:other`: El gate completo consume tiempo de runner y retrasa el feedback de los PRs de una sola app, un impacto operativo concreto fuera de las categorías funcionales.

## Summary

Debe mantenerse abierta: `dev` ya evita el gate pesado para cambios solo documentales, pero cualquier cambio de código continúa ejecutando todos los workspaces y suites; tampoco existe una PR abierta o un elemento canónico que cubra la granularidad solicitada.

## What This Changes

La issue solicita limitar lint, typegen, typecheck y suites de tests de CI al grafo de workspaces afectados, manteniendo el gate completo ante cambios globales o fallos de detección.

## Best Possible Solution

Calcular una sola lista validada de workspaces afectados y pasarla de forma opt-in al gate compartido, conservando el comportamiento completo ante archivos globales, diffs ambiguos, listas vacías o cualquier error.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, con alta confianza desde fuente: cualquier cambio de código activa el mismo script completo y las cinco suites, aunque solo afecte a una app. No fue necesario ejecutar GitHub Actions para confirmar esta ruta estática.

## Solution Assessment

Sí, con un ajuste de seguridad: el scoping debe ser opt-in para `scripts/ci-checks.sh` y usar una única lista de afectados validada, en lugar de autodetectar silenciosamente en cada consumidor.
