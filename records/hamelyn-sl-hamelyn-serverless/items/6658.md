## Summary

La incidencia sigue siendo necesaria: `dev` continúa reteniendo para reintento un `ORDER_CHANGE` `Unshipped` cuando el formatter no resuelve ningún stock, sin aplicar un destino terminal específico.

## What This Changes

Evitar que `amazon-notifications-pull` reintente indefinidamente pedidos Amazon cuyo SKU ya no existe en la base de datos.

## Best Possible Solution

Añadir un resultado estructurado para `missing_stock`, registrar una única auditoría y consumir el mensaje tras crear `TO_CANCEL` solo si se aprueba esa semántica operativa.
