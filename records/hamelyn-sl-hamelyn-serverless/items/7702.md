## What This Changes

Migrar el muestreo de `rotate-flash-offers` desde agregaciones sobre MongoDB a una consulta de BigQuery, manteniendo una vía explícita de rollback a MongoDB.

## Best Possible Solution

Corregir y revisar https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7710 antes de integrarlo: conservar el fallback español para locales sin candidatos, priorizar el idioma desnormalizado de `stocks` y definir una ruta de rollback realmente ejecutable y documentada para el cron.
