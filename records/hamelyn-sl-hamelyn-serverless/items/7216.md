## Summary

Mantengo esta issue abierta: la rama `dev` todavía conserva la semántica `acceptedBy`/`acceptedAt` y borra la traza al rechazar, mientras que el PR abierto que declara cerrarla aún no está mergeado.

## What This Changes

La issue pide trazar `reviewedAt`/`reviewedBy` por producto en cada revisión, tanto si el operador acepta como si rechaza.

## Best Possible Solution

Revisar y aterrizar el PR abierto que implementa la traza por producto, validando compatibilidad histórica, reporting y la decisión de base antes de cerrar esta issue.
