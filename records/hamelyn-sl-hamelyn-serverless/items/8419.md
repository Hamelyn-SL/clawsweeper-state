## Summary

El PR sigue aportando una reescritura útil, pero el head actual deja bloqueos en recuperación, confirmación de pedidos y comprobación de cancelaciones que no son seguros para integrar.

## What This Changes

El PR reemplaza la integración de AbeBooks con un cliente XML por lotes y modifica inventario, pedidos, envío, recuperación de errores y documentación operativa.

## Best Possible Solution

Alinear la recuperación con el nuevo formato de errores, persistir de forma segura los pedidos antes de confirmar el siguiente y rotar la revisión de cancelaciones antes de integrar la reescritura.
