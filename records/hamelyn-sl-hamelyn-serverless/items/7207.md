## Summary

Mantener abierto: el PR contiene arreglos útiles para el E2E de Supply, pero la cabeza actual no está lista para merge porque mete credenciales E2E en una ruta `EXPO_PUBLIC_*` que consume la app y falta prueba real visible del bootstrap ROPC añadido después.

## What This Changes

El PR cambia el workflow E2E de Supply a Node 22, alinea el `testID` del tab Home, sube artefactos de Maestro y sustituye el login UI por un bootstrap ROPC de Auth0 en modo E2E.

## Best Possible Solution

Mantener el arreglo de `testID`, Node 22 y artefactos, pero mover la autenticación E2E a una ruta que no empaquete contraseñas en la app, por ejemplo token generado fuera del bundle e inyección solo-test con prueba real redactada.
