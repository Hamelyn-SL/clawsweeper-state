## Summary

La incidencia sigue siendo necesaria: `pt-BR` continúa excluido y las URLs públicas de categoría/subcategoría se renderizan mediante `SearchPage` sin alternates; extender esa metadata requiere resolver una decisión SEO documentada para las búsquedas.

## What This Changes

Añadir alternates `hreflang` recíprocos a las categorías públicas y sumar `pt-BR` al clúster internacional de ecommerce.

## Best Possible Solution

Mantener las búsquedas libres sin hreflang y crear una vía explícita para que solo los aliases públicos de categoría/subcategoría generen el clúster recíproco, incluido `pt-BR`.
