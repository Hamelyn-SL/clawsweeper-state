## Summary

Mantener abierta: el parche acota bien la mutación de `DB_ONLY`, pero falta validar el flujo contra eBay, Mongo y BigQuery reales y confirmar la política para respuestas `404` y estados no publicables.

## What This Changes

El PR consulta Inventory API por cada SKU ausente del informe eBay antes de persistir `SYNC_ERROR/DB_ONLY`, preservando como `BOTH` las ofertas vivas.

## Best Possible Solution

Conservar la comprobación remota previa a la mutación, aprobar explícitamente el tratamiento de `404` y estados no publicables, y demostrarlo en una ejecución redacted del workflow real.
