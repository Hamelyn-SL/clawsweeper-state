## What This Changes

The issue requests delivery tracking events for SEUR, FEDEX, and CORREOS to be written into `ordersells.trackingEvents` for downstream review-email detection.

## Best Possible Solution

Add a bounded OrderSell tracking sync that reuses `CarrierManager`, deduplicates persisted events, records enough sync state to avoid repeated carrier polling, and normalizes delivered events for all three requested carriers.
