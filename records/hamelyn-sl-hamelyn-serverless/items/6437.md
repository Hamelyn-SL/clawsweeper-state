## Summary

La necesidad sigue vigente en `dev`: el cron solo selecciona `Order`, mientras que las ventas de marketplace con SEUR, FEDEX y CORREOS no tienen una ruta automática que actualice `ordersells.trackingEvents`.

## What This Changes

Añadir sincronización de tracking para ventas `OrderSell` de SEUR, FEDEX y CORREOS, persistiendo los eventos nuevos de entrega.

## Best Possible Solution

Extender el cron para seleccionar `OrderSell` pendientes, reutilizar deduplicación y persistencia existentes, y añadir una normalización de CORREOS verificada para la detección de entrega.
