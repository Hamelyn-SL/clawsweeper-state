## Summary

La issue sigue siendo necesaria: `dev` persiste `trackingEvents` en `OrderSell`, pero el cron de sincronización solo selecciona y procesa `Order`; SEUR, FEDEX y CORREOS no tienen una ruta equivalente para rellenar automáticamente los eventos de las ventas. Gracias por el diagnóstico previo: coincide con el código actual y no hay una PR abierta que posea este trabajo.

## What This Changes

Añadir sincronización de eventos de entrega de SEUR, FEDEX y CORREOS en `ordersells.trackingEvents` para poder detectar entregas de ventas como las de Discogs.

## Best Possible Solution

Extender el sincronizador compartido para seleccionar `OrderSell` elegibles de SEUR, FEDEX y CORREOS, persistir solo eventos deduplicados y normalizados, y registrar una cadencia de consulta que finalice al detectar `ENTREGADO`.
