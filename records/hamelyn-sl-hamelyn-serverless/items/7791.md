## Summary

La incidencia sigue presente en `dev`: el endpoint espera toda la prueba y el feedback solo se publica al final. El PR enlazado sigue abierto y su propia prueba documenta casos aún incumplidos, por lo que esta incidencia debe permanecer abierta hasta corregirlo e integrarlo.

## What This Changes

La incidencia solicita que cada ejecución del Proof Agent publique `EN CURSO` al aceptar el trabajo y termine con veredicto, `infrastructure_error` u `OBSOLETO`.

## Best Possible Solution

Corregir e integrar el candidato para persistir una ejecución idempotente por PR y SHA, publicar el estado inicial antes del trabajo largo y cerrar de forma segura cada ejecución sin sobrescribir el feedback del SHA vigente.
