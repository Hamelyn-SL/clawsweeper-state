## Summary

El issue sigue siendo necesario: en `dev` continúan las entradas de menú, el `dashboard={HomePage}`, los `Resource` de `dashboard/*` y el iframe `v4/admin/data/graphs`. No conviene cerrarlo como implementado; el único bloqueo real es decidir qué hacer con las rutas públicas que reutilizan paneles de `Dashboards/`.

## What This Changes

Se solicita retirar del admin las entradas "Panel de control" y "Gráficos", borrar los dashboards de Atlas Charts asociados y limpiar el frontend muerto resultante.

## Best Possible Solution

Retirar primero las rutas y entradas internas del admin, decidir explícitamente si las rutas públicas se eliminan o se conservan moviendo sus paneles fuera de `dashboard/`, y validar `admin` con lint y typecheck focalizados.
