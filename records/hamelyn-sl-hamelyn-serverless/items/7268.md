## Label Justifications

- `P1`: El flujo de soporte de Supply para incidencias de ventas lleva a una ruta que no fuerza login, afectando a usuarios reales que intentan abrir una incidencia desde contacto.
- `impact:ux-friction`: El usuario no autenticado puede quedar en una lista vacía o sin camino claro desde la tarjeta, aunque puede recuperar el flujo iniciando sesión por otra vía.

## Summary

Debe seguir abierta: en `dev` el acceso de Supply desde `/contacto` a "Problemas con un lote" navega directamente a `routes.profile.sales` sin comprobar sesión ni lanzar Auth0, así que el flujo descrito sigue fallando para usuarios no autenticados.

## What This Changes

Se pide que el acceso "Problemas con un lote" de `https://hamelyn.com/contacto` lleve a inicio de sesión cuando no hay sesión y después abra el perfil de Ventas.

## Best Possible Solution

Hacer que la tarjeta de Supply detecte sesión: si no hay usuario, iniciar Auth0 con retorno a `routes.profile.sales`; si ya hay sesión, mantener la navegación directa a Mis ventas.
