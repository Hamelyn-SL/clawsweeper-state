## Summary

La issue sigue siendo necesaria: `dev` conserva el export estático y la generación física de rutas localizadas. La mejora de sitemap ya mergeada reduce una parte del problema, pero no implementa la arquitectura propuesta ni existe otra issue o PR canónica que la sustituya.

## What This Changes

Migrar Supply web desde builds estáticos con rutas localizadas generadas a una fuente única de slugs, rewrites de Expo Router, renderizado servidor y SEO multiidioma por request.

## Best Possible Solution

Mantener una épica por fases: primero crear una fuente tipada única de slugs con validación de paths completos y colisiones; después desplegar una PoC aislada de server output en staging que pruebe URLs localizadas, hidratación, Auth0, analítica, HTML por locale y rollback; solo entonces aprobar la migración del deploy y añadir loaders exclusivamente a páginas con datos remotos que aporten valor SEO.
