## Summary

La necesidad central sigue pendiente en `dev`: Supply conserva export estático, generación física de rutas localizadas y metadatos dependientes del idioma de build. La corrección del sitemap redujo un síntoma relacionado, pero no sustituyó la migración propuesta.

## What This Changes

Migrar Supply web a rutas localizadas declarativas con rewrites y SSR por request mediante Expo Router server output.

## Best Possible Solution

Aprobar un PoC aislado en staging para server output y, si supera rutas, hidratación, Auth0 y rollback, ejecutar después la migración por fases desde una fuente única de slugs.
