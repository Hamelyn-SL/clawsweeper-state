## Summary

La incidencia sigue siendo necesaria: `dev` conserva la ruta que excluye de `DB_ONLY` cualquier SKU presente en el report, aunque no sea vendible. La PR abierta vinculada propone el arreglo y aporta prueba aislada, pero no debe cerrar esta issue hasta que se decida y aterrice la semántica terminal de esa cohorte.

## What This Changes

La incidencia pide que la reconciliación Amazon no mantenga `ACTIVE` local para listings presentes en el report pero sin oferta vendible confirmada.

## Best Possible Solution

Aprobar un contrato explícito para listings reportados pero no vendibles y, si se acepta `REPORT_INACTIVE`, integrar la PR con un primer run monitorizado que compruebe readmisión al volver `Active` con cantidad 1.
