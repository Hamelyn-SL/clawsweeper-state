## Label Justifications

- `P1`: La discrepancia afecta al flujo real de publicación Amazon y puede sostener estados locales engañosos para cohortes grandes.
- `impact:other`: El impacto principal es la divergencia entre estado operativo local y disponibilidad seller, fuera de las clases específicas disponibles.

## Summary

La incidencia sigue siendo necesaria: `dev` aún marca como `ACTIVE` resultados aceptados y el reconciliador solo degrada SKU ausentes del report. La PR vinculada aporta una parte del arreglo, pero tiene bloqueadores de semántica y seguridad operativa antes de resolver el problema completo.

## What This Changes

Separar la aceptación de creación en Amazon FR de la activación efectiva del seller para evitar que el estado local `ACTIVE` se interprete como una conversión confirmada.

## Best Possible Solution

Definir un contrato de estados que conserve la aceptación remota, distinga activación confirmada y mantenga las retiradas de listings existentes; después, corregir y validar la PR vinculada por región antes de desplegarla.
