## Summary

Mantener abierta: en `dev` la ficha sigue sin aplicar el fallback `×1,37`; la spec BL-06, el helper compartido y los tests actuales documentan expresamente la divergencia pendiente, y la issue ya está asignada con WIP local anunciado.

## What This Changes

La issue pide que la ficha ecommerce use el precio base más barato `×1,37` como precio tachado cuando no hay precio de nuevo conocido, actualizando también la spec y el test BL-06.

## Best Possible Solution

Publicar y revisar una PR acotada que cambie el helper compartido de referencia, use `getMinUsedPrice(visibleAvailability)` como base del fallback cuando falte precio nuevo, y actualice la spec/test BL-06 en el mismo cambio.
