## What This Changes

La issue pide que la retirada masiva de Amazon derive sus regiones desde la configuración/factory común en lugar de mantener una lista manual por país en el controller.

## Best Possible Solution

Integrar una única definición Amazon exhaustiva que exponga tanto el factory de marketplace como la capacidad de batch withdraw, y cerrar esta issue cuando el PR candidato se haya revisado y mergeado en `dev`.

## Solution Assessment

Sí, la dirección propuesta es la más mantenible: mover la capacidad de batch withdraw a una configuración Amazon exhaustiva y hacer que el cron itere esa fuente única. El PR abierto debe validarse como implementación concreta antes de cerrar la issue.
