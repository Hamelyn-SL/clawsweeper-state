## Summary

El PR aporta mejoras útiles, pero no es integrable aún: la nueva consulta de pedidos no reconcilia cancelaciones ya importadas y la eliminación de SigV4 sigue sin prueba real para POST.

## What This Changes

El PR elimina la firma SigV4 de SP-API y modifica la creación de listings, el catálogo y la importación de pedidos Amazon compartida.

## Best Possible Solution

Incorporar una reconciliación explícita y segura de cancelaciones Amazon, filtrar antes del límite y demostrar el transporte LWA en operaciones reales antes de activar el cambio común.
