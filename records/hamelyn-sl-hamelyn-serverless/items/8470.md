## Summary

Este PR aporta mejoras útiles, pero no debe fusionarse aún: elimina la autenticación firmada de un POST de envío sin prueba real y puede crear pedidos con importes incorrectos al filtrar cancelaciones.

## What This Changes

La rama elimina SigV4 de las llamadas Amazon y ajusta restricciones de listings, lotes de catálogo y la ingestión de pedidos cancelados.

## Best Possible Solution

Mantener la autenticación previa para POST hasta demostrar `confirmShipment`, y recalcular o descartar pedidos tras eliminar ítems con cancelación ejecutada.

## Solution Assessment

No: el cambio global de autenticación debe conservar el POST no probado, y la cancelación debe ajustar totales o descartar pedidos sin líneas vendibles.
