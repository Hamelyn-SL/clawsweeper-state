## Summary

Mantener abierta: `dev` ya acredita el tracking REST y la creación de etiquetas RMA para Supply, pero los documentos siguen señalando como pendientes el manual contractual vigente, el contacto operativo y una referencia autorizada para custodiar las credenciales; ninguna issue o PR más reciente ha asumido ese remanente.

## What This Changes

Completar la documentación operativa de Celeritas con el contrato vigente, el alcance real de sus flujos, el contacto técnico y la referencia segura de configuración.

## Best Possible Solution

Dejar documentados por separado el tracking, la creación RMA de Supply y la ausencia o presencia de creación para marketplace; después enlazar el manual y el contacto confirmados y sustituir las referencias legacy por nombres de configuración o una ubicación aprobada en el gestor de secretos, sin copiar valores.
