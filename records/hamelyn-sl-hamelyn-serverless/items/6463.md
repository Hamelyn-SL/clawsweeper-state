## Summary

Mantener abierta: `dev` ya acredita el tracking REST y un flujo de etiquetas RMA para Supply, pero no contiene el manual contractual vigente, el contacto operativo ni una referencia autorizada para custodiar las credenciales; la issue sigue siendo el seguimiento canónico de esas confirmaciones.

## What This Changes

Confirmar el contrato, alcance operativo, contacto técnico y referencia segura de configuración de Celeritas, y reflejarlos en los runbooks de integraciones.

## Best Possible Solution

Conservar un runbook que distinga claramente el tracking de marketplace gestionado por `CarrierManager` del flujo RMA de etiquetas de Supply, enlazando el manual y contacto confirmados y citando únicamente la referencia aprobada del gestor de secretos; cualquier migración o rotación debe quedar verificada antes de retirar las constantes legacy.
