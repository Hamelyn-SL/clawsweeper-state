## Label Justifications

- `P1`: La issue reporta fallos recurrentes en producción en el cron de creación de Amazon SE que afectan a la publicación de stocks en marketplace.
- `impact:other`: El impacto concreto es degradación operativa de sincronización/publicación de catálogo en Amazon SE, fuera de las categorías más específicas de ClawSweeper.

## Summary

Mantener abierta. La ruta de código actual sigue produciendo `No ASIN found for this EAN` cuando Amazon SE no puede resolver ASIN, y la issue tiene evidencia fresca de producción del 2026-07-08/09 después de cierres previos, así que `dev` no demuestra que el problema esté resuelto.

## What This Changes

La issue pide resolver o decidir el tratamiento de los fallos de `create` en Amazon SE cuando no se puede resolver un ASIN desde el EAN.

## Best Possible Solution

Validar en vivo la recurrencia por SKU frente a `lastUpdatedTimestamp`; después, corregir una fuga real de cooldown o definir explícitamente una política de enriquecimiento, exclusión/no elegibilidad o limitación documentada para Amazon SE sin ASIN.

No está claro todavía. La recuperación con cooldown de 24h es una solución parcial mantenible, pero la señal posterior exige validar si se incumple el cooldown o si falta una política terminal/no elegible para Amazon SE.
