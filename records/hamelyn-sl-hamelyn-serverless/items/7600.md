## Summary

Este PR sigue siendo necesario, pero no debe fusionarse todavía: el fallback de precios ausentes produce un reparto financiero incorrecto en casos mixtos, permanece un hallazgo documental de la revisión anterior y falta prueba real posterior del flujo persistido.

## What This Changes

El PR añade un helper con pruebas para repartir proporcionalmente `totalPrice` entre las ventas resultantes de una cancelación parcial y documenta la semántica de moneda.

## Best Possible Solution

Usar los precios como pesos solo cuando todas las líneas relevantes los tengan y aplicar un fallback determinista por unidades cuando falte alguno; después acotar la documentación, retirar la atribución automática y demostrar los dos `OrderSell` persistidos en una ejecución real.
