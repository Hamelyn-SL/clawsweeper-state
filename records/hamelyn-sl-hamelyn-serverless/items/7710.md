## Summary

El PR sigue siendo necesario para la migración de Flash Offers, pero no debe integrarse aún: falta prueba observable del recorrido GCP→GitHub→KV y la documentación del nuevo modo `exists` no coincide con su contrato.

## What This Changes

El PR elimina el cron fijo de Flash Offers, dispara la rotación tras `stocks_daily_materialize` y reemplaza el muestreo Mongo por una consulta batch de BigQuery.

## Best Possible Solution

Completar una prueba controlada y redaccionada del primer recorrido desplegado y de un segundo evento del mismo bucket; después, mantener el rollback manual Mongo documentado para incidencias operativas.
