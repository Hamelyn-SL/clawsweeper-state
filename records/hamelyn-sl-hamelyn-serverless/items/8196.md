## Label Justifications

- `impact:other`: El impacto es una retirada incompleta de inventario en MercadoLibre, fuera de las clases específicas disponibles.

## Summary

La incidencia sigue siendo necesaria: `dev` ya recupera IDs por `seller_sku`, pero el selector de retirada deja fuera los documentos `INACTIVE/WITHDRAWN` descritos. La reconciliación abierta cubre parte del caso, aunque aún no demuestra el cierre productivo de esta cohorte.

## What This Changes

Corregir listings hermanos de MercadoLibre que permanecen comprables tras marcar como retirado un SKU vendido localmente.

## Best Possible Solution

Extender y validar la reconciliación para incluir esta cohorte histórica, cerrar sólo listings vivos con stock no vendible y confirmar en API que los 32 IDs pasan a estado terminal.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, por fuente: una fila con `stockStatus=WITHDRAWN` y estado local `INACTIVE` no cumple el selector actual, aunque tenga un listing hermano vivo.

## Solution Assessment

No del todo: recuperar IDs por `seller_sku` es correcto, pero debe ir acompañado de una ruta de reconciliación que vuelva a seleccionar los residuos históricos.
