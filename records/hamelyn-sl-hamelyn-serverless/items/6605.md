## Summary

Gracias por el contexto: `dev` ya genera etiquetas Meli y puede enviar adjuntos, pero no automatiza el lote diario ni define exclusiones, horario, idempotencia o trazabilidad; la decisión operativa sigue pendiente.

## What This Changes

La solicitud pide enviar de lunes a viernes un correo con las etiquetas diarias de Mercado Libre, excluyendo las ventas canceladas.

## Best Possible Solution

Definir un lote interno diario de `orderSell` Meli elegibles, con exclusiones verificables, registro de envío e idempotencia; después añadir un cron que genere el adjunto y use el servicio de correo existente.
