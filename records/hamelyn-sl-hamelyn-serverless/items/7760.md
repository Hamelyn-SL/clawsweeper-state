## Label Justifications

- `P2`: Es una mejora comercial planificable que reduce dependencia de despliegues, pero no bloquea actualmente la compra ni la operación básica.
- `impact:ux-friction`: El copy estático puede quedar desalineado con una promoción real y generar confusión o soporte sin impedir continuar en la tienda.

## Summary

La funcionalidad sigue pendiente: el banner visible aún toma copy y cupón de i18n estático, sin configuración compartida ni editor en Admin. Requiere una decisión de producto sobre la fuente de verdad antes de implementar.

## What This Changes

La issue solicita editar desde Admin el copy localizado, formato B/I, variante visual y previsualización del banner promocional que muestra Ecommerce.

## Best Possible Solution

Definir una campaña promocional tipada por entorno y locale, vinculada al cupón aplicable, con variantes cerradas y markup limitado; después conectarla a un editor Admin y a `PromoStrip` con fallback de despliegue controlado.
