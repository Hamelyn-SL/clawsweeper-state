## Summary

La funcionalidad sigue pendiente: Ecommerce aún obtiene el texto del strip desde i18n estático y no existe una configuración promocional tipada, editable y compartida entre Admin y la tienda.

## What This Changes

La issue solicita un banner promocional editable desde Admin por locale, con formato limitado, estilos cerrados y vista previa, para que Ecommerce lo renderice desde esa configuración.

## Best Possible Solution

Definir un contrato Zod compartido de promoción por locale, vinculado a la campaña activa cuando corresponda, y exponerlo mediante APIs autenticada y pública con fallback temporal a i18n.
