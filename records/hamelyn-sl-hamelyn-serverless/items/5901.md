- `impact:other`: El impacto principal es la recuperación de operaciones de marketplace, sin evidencia de pérdida de datos, auth o entrega de mensajes.

## Summary

La incidencia sigue siendo necesaria: el polling normal de batches Fnac llama directamente al procesador y omite la ruta existente de reintento para errores temporales, mientras la señal de 500 volvió a aparecer en producción.

## What This Changes

Evitar que respuestas 500 transitorias de Fnac retrasen o degraden la sincronización de pedidos, ofertas y batches del cron.

## Best Possible Solution

Usar el retry existente solo para el polling idempotente de `/batch_status`, conservando sin reintento automático los POST mutables de ofertas y pedidos, y comprobar el comportamiento con un batch real o una traza redacted.
