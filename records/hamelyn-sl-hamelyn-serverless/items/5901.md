## Summary

La incidencia sigue siendo necesaria: un error global de batch de Fnac se persiste como `SYNC_ERROR` transitorio, pero el siguiente cron solo vuelve a seleccionar filas `BATCH` y deja ese batch sin nuevo sondeo.

## What This Changes

La incidencia solicita recuperar de forma segura los errores HTTP 500 de Fnac en pedidos, retirada de ofertas y estado de batch, sin mezclar el flujo de envío ya tratado aparte.

## Best Possible Solution

Volver a sondear en el siguiente cron solo los batches Fnac con `BATCHING` y `RetryPolicy.TRANSIENT`, conservando el mismo `batchId` y sin reenviar `offers_update`.
