## Summary

Conviene mantenerla abierta: el `dev` actual sigue calculando la urgencia por importe en seis importadores activos, la spec conserva la divergencia y no existe otro issue o PR que haya asumido o resuelto el cambio contractual pendiente.

## What This Changes

Derivar `shipPriority` del nivel de servicio o método de envío informado por cada marketplace, usando el umbral por importe únicamente como fallback explícito.

## Best Possible Solution

Aprobar una matriz por marketplace que identifique la señal primaria, los valores equivalentes a `URGENT` y el fallback permitido; implementarla como lógica de dominio testeable, ampliar los parsers donde sea necesario y actualizar conjuntamente la spec y sus tests BL.
