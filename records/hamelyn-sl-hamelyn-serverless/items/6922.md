## Summary

La divergencia sigue activa en `dev`: CDL, eBay y Fnac conservan la señal de servicio pero calculan `shipPriority` desde el importe. El censo reciente elimina la duda de cobertura, pero faltan dos mapeos contractuales antes de cambiar SLA.

## What This Changes

La issue pide usar el nivel de servicio de cada marketplace para `shipPriority`, manteniendo el importe solo como fallback cuando no haya señal.

## Best Possible Solution

Aprobar una tabla versionada de códigos por marketplace, priorizarla en CDL, eBay y Fnac con fallback desconocido por importe, y decidir explícitamente el tratamiento de `fulfillmentServiceLevel` en Amazon.
