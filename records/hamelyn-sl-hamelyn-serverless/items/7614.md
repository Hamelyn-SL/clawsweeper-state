## Label Justifications

- `P2`: Es una vulnerabilidad alta de disponibilidad en importaciones XLSX autenticadas, sin evidencia de explotación activa y con una remediación técnicamente acotada.
- `impact:security`: La versión runtime de `xlsx` está afectada por ReDoS al procesar libros externos mediante `XLSX.read()`.

## Summary

Debe seguir abierta: `dev` todavía resuelve `xlsx` 0.18.5, afectada por GHSA-5pgg-2g8v-p4x9, y varias rutas runtime entregan archivos externos directamente a `XLSX.read()`. No hay una PR abierta ni una corrección equivalente en la rama por defecto.

## What This Changes

La issue solicita actualizar `xlsx` a una distribución corregida de SheetJS para evitar ReDoS al procesar archivos XLSX externos.

## Best Possible Solution

Mantener una única versión oficial y fijada de SheetJS `>= 0.20.2` para `admin` y `@hamelyn/core`, con integridad reproducible y pruebas reales de importación y generación XLSX que cubran ambas alertas.
