## Summary

La issue permanece abierta: `dev` sigue exportando desde MongoDB y la PR vinculada aún no se ha fusionado. Además, el gate de frescura no cambia automáticamente a MongoDB cuando vence, por lo que falta cerrar ese contrato antes de promoverla.

## What This Changes

Migrar el export diario de inventario de Alibris desde el escaneo de `stocks` en MongoDB a `mongodata.stocks` de BigQuery, conservando un fallback operativo a MongoDB.

## Best Possible Solution

Completar https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7988 con una política explícita ante datos stale, corregir la documentación del backfill y fusionarla tras validar el primer export y el relleno histórico.
