## Label Justifications

- `P1`: La falta de teléfono del destinatario afecta la coordinación de entregas y aparece en una mayoría de pedidos Fnac examinados por el triaje.
- `impact:other`: El problema afecta la operativa de entrega de marketplace, sin evidencia suficiente todavía para clasificarlo como pérdida de datos.

## Summary

La incidencia sigue siendo necesaria: el importador actual guarda el teléfono de ATC cuando Fnac no rellena `shipping_address.mobile` ni `shipping_address.phone`, que coincide con los pedidos afectados. Falta el payload original para saber si Fnac omite el dato o si llega en una clave que el esquema descarta.

## What This Changes

Corregir la importación de pedidos Fnac para conservar el teléfono real del cliente en lugar del número predeterminado de ATC cuando esté disponible.

## Best Possible Solution

Obtener una respuesta `orders_query` enmascarada de un pedido afectado, ampliar el esquema y el mapeo solo para la clave confirmada, y añadir cobertura para móvil, teléfono alternativo y fallback de ATC.
