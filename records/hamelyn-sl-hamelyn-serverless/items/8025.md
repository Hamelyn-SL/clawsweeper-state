- `impact:other`: El impacto confirmado es operativo en la entrega y no encaja con las clases específicas de mensajes, sesión o autenticación.

## Summary

La incidencia sigue siendo necesaria: `dev` conserva el teléfono recibido de Fnac, pero cuando ambos campos llegan vacíos guarda el número por defecto de ATC, que coincide con el síntoma comunicado.

## What This Changes

Corregir la importación de pedidos de Fnac para que el teléfono almacenado sea el contacto real del destinatario cuando Fnac lo proporcione.

## Best Possible Solution

Capturar de forma segura la respuesta de Fnac para pedidos afectados, mapear el campo de destinatario correcto y añadir una prueba de regresión que preserve el fallback solo cuando no exista contacto útil.
