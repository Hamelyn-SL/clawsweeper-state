## Summary

Añade el caso `Carrier.SPRING` a `formatShippingMethod` para enviar `"TRCK (TRACKED)"` en la confirmación REST de envíos de Amazon.

## Best Possible Solution

Integrar el mapeo de Spring tras completar los gates normales, manteniendo `"FBM"` como fallback para los demás carriers no especializados.
