## Summary

La rama sigue siendo necesaria para resolver la incidencia enlazada, pero no está lista para merge: anuncia capacidades v2 aunque falta el credencial necesario para leer el ledger privado, y la prueba autoritativa actual termina en `inconclusive`.

## What This Changes

La rama sustituye el gate de PR Proof por un protocolo v2 con estado autoritativo, checks de GitHub App, ledger ligado y comprobaciones causales.

## Best Possible Solution

Hacer que capabilities compruebe el lector de ledger y degrade a protocolo no disponible antes de crear runs; después demostrar en staging un ciclo real terminal con logs y ledger redactados.
