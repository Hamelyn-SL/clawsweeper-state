## Label Justifications

- `P1`: Un gate que puede aprobar instrucciones ejecutables sin evidencia causal afecta directamente la seguridad de integración.
- `merge-risk: 🚨 security-boundary`: La nueva ruta `text-delta` puede otorgar éxito a contenido Markdown que actúa como prompt o instrucción ejecutable.
- `merge-risk: 🚨 automation`: La reconciliación incompleta tras cierre puede dejar checks y ejecuciones de Proof fuera del ciclo esperado.
- `merge-risk: 🚨 availability`: Ejecuciones no supersedidas al cerrar una PR pueden continuar consumiendo el backend y publicar resultados tardíos.

## Summary

La rama sigue siendo necesaria como hardening adicional, pero conserva dos bloqueadores verificables en el gate: puede aprobar instrucciones ejecutables mediante `text-delta` y no reconcilia cierres sin SHA de merge. Además, la prueba vigente es `NO CONCLUYENTE`.

## What This Changes

La rama refuerza PR Proof con estado autoritativo v2, checks dedicados, ledger enlazado, una GitHub App con roles separados y verificadores causales adicionales.

## Best Possible Solution

Restringir `text-delta` a documentación inequívocamente no ejecutable, derivar la barrera de cierre del último run autoritativo y aportar un canario redactado de extremo a extremo antes de activar el gate.
