## Summary

La rama no está lista para merge: dos rutas nuevas permiten que un harness no confiable obtenga un PASS del gate sin demostrar el comportamiento reclamado.

## What This Changes

La rama amplía PR Proof con un gate v2, checks dedicados de GitHub App y un verificador diferencial `causal_probe` para cambios deterministas.

## Best Possible Solution

Mantener `causal_probe` como diagnóstico hasta que un verificador versionado enlace el criterio, las rutas ejecutadas y el observable; usar `invoke_export` para los PASS actuales.
