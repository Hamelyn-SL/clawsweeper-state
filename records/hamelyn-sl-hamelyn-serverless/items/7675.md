## Summary

Debe mantenerse abierta: el fallo sigue presente en `dev`. La Preview demostró que la dirección del arreglo funciona, pero el cambio no está versionado y no existe una PR de implementación abierta.

## What This Changes

La issue solicita corregir el mapeo de workspaces del resolvedor cloud para usar la raíz real del checkout y conservar el diagnóstico original cuando falle.

## Best Possible Solution

Versionar el arreglo validado en Preview: resolver `git rev-parse --show-toplevel`, leer manifiestos con rutas absolutas, preservar `cwd`, workspace y error original, y cubrir `apps/*`, `packages/*` y rutas inseguras antes de reactivar producción.

## Solution Assessment

Sí. Fijar explícitamente la raíz del checkout y conservar el error original corrige la causa sin relajar el gate de seguridad; debe acompañarse de cobertura focalizada y una validación end-to-end antes de activar el servicio.
