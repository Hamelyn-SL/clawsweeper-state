## Summary

La incidencia sigue siendo necesaria: `dev` combina una selección por cookie con un shell de layout cacheado, y la home pública devuelve el mismo HTML cacheado para visitantes distintos. Hace falta validar la frontera de streaming antes de corregirlo.

## What This Changes

Corregir el desajuste de hidratación de la promo strip para que cada visitante reciba una variante A/B estable sin contaminar el HTML compartido en caché.

## Best Possible Solution

Mantener el shell cacheado y mover la selección por cookie a una frontera realmente no cacheada; añadir una prueba con dos visitantes y validar HTML, Flight e hidratación sin `#418`.
