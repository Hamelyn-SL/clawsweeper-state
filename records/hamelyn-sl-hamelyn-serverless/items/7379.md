- `P1`: La issue documenta listings de Amazon ES que siguen activos con oferta mientras Hamelyn no conserva fila local para retirarlos, con riesgo operativo real de sobreventa.

## Summary

Mantener abierta: la evidencia del reporte es concreta y el código actual confirma que Amazon ES no descubre listings activos sin fila `mk_amazonEs` por la retirada normal. No hay señal de que `dev` ya lo haya resuelto; el siguiente paso requiere decisión operativa antes de tocar datos/listings externos en masa.

## What This Changes

La issue pide que Amazon ES pueda retirar listings propios activos en Amazon aunque falte la fila local correspondiente en `stocks_marketplace` / `mk_amazonEs`.

## Best Possible Solution

Ejecutar un dry-run aprobado para la cohorte de Amazon ES, validar una muestra fresca contra SP-API y decidir si se rehidrata `mk_amazonEs` para entrar por el pipeline de retirada o si se envía una retirada/cantidad 0 directa desde el snapshot externo.
