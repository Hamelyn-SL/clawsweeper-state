## Repair Work Prompt

Corrige https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7523 en `apps/hamelyn-ecommerce/app/api/v5/checkout/route.ts`. Cuando `getAddressFromBody` no resuelva una dirección, conserva el mensaje `Address not found` pero lanza `CheckoutRequestError` con status 422 y cambia a 422 el status incluido en el payload de Slack. Verifica de forma focalizada que este caso devuelve 422, que la alerta operativa usa 422 y que un error inesperado continúa devolviendo 500. Mantén el cambio en el handler existente; no refactorices otros errores, no cambies la lógica de selección de direcciones, no añadas configuración y no versiones scripts one-time. Ejecuta Prettier, lint, `next typegen` y typecheck del workspace ecommerce. No se requiere cambio de changelog para este arreglo interno.
