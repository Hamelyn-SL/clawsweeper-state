## Summary

Gracias por el contexto: el flujo actual todavía devuelve `LABEL_NOT_FOUND` cuando falta la etiqueta persistida. Hay una corrección abierta y vinculada que declara resolver exactamente ese caso, por lo que esta incidencia debe permanecer abierta hasta revisarla e integrarla.

## What This Changes

Recuperar bajo demanda la etiqueta de MercadoLibre ausente para que Auto Packing pueda generar el documento de impresión.

## Best Possible Solution

Integrar la recuperación canónica solo para MercadoLibre tras una validación en staging con una etiqueta realmente ausente, confirmando que el documento llega a Gutemberg y que otros carriers no cambian.
