El PR cambia 13 workflows cron de GitHub Actions para usar `pnpm install --frozen-lockfile --filter local...`, elimina el build de `@hamelyn/core` y actualiza la skill `hamelyn-knowledge`.

## Best Possible Solution

Mantener `--filter local...` solo en workflows cuyo entrypoint vive en `apps/local`, tratar `amazon-returns-pendings` con un setup explícito y pineado para `.github/scripts`, y ajustar la documentación de la skill para reflejar esa excepción.
