## Summary

La adopción sigue pendiente en `dev`: el repositorio conserva TypeScript 6 como única dependencia y CI no tiene aún un canario o caché separada para TypeScript 7. Requiere decidir el rollout antes de implementar.

## What This Changes

La issue solicita una adopción progresiva de la CLI nativa de TypeScript 7 sin sustituir todavía la API TypeScript 6 usada por Next.js y ESLint.

## Best Possible Solution

Mantener TypeScript 6 como gate estable y crear un canario opt-in de TypeScript 7 con aliases, comandos, `.tsbuildinfo` y cachés por major antes de valorar el rollout global.
