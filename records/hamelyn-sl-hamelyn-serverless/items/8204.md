## Summary

La adopción no está implementada: `dev` mantiene TypeScript 6 como API y CLI, sin aliases ni canario TypeScript 7. Tras integrarse Next.js 16.3, sigue faltando una decisión de plataforma sobre la coexistencia y sus gates.

## What This Changes

La issue pide diseñar y validar un rollout progresivo de la CLI nativa de TypeScript 7 conservando temporalmente la API de TypeScript 6.

## Best Possible Solution

Aprobar un canario no bloqueante con aliases, caches y `tsbuildinfo` separados; promover TypeScript 7 sólo tras igualar diagnósticos, builds y emisión de `@hamelyn/core`.
