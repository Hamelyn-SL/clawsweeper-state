## Summary

La adopción no está implementada: `dev` mantiene la API y la CLI en TypeScript 6.0.3. El alcance exige acordar un canario y una política de coexistencia antes de convertirlo en trabajo de cambio.

## What This Changes

Evaluar una transición progresiva a la CLI nativa de TypeScript 7 sin sustituir todavía la API TypeScript 6 que consumen Next.js y ESLint.

## Best Possible Solution

Definir un canario aislado que preserve TypeScript 6 por defecto, separe cachés por major y exija resultados de build, typegen, lint, emisión de `@hamelyn/core` y rendimiento antes de un rollout global.
