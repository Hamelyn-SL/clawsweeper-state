## Summary

La adopción de TypeScript 7 sigue pendiente: `dev` conserva TypeScript 6 como API y CLI, sin aliases, canario ni separación de cachés por major. Requiere una decisión de plataforma antes de preparar una migración segura.

## What This Changes

Diseñar y validar una coexistencia progresiva de CLI nativo TypeScript 7 y API TypeScript 6, con canario de CI y plan de retirada.

## Best Possible Solution

Acordar un canario opt-in con aliases, comandos y cachés separados; promoverlo solo tras igualar diagnósticos, builds y emisión de `@hamelyn/core` frente a TypeScript 6.
