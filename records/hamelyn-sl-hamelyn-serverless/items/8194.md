## Label Justifications

- `P1`: Cambia la fuente y el disparador de feeds de producción de Google Merchant con posible impacto inmediato en publicaciones.
- `merge-risk: 🚨 compatibility`: El valor por defecto sustituye lecturas vivas de Mongo por metadata diaria de BigQuery sin un gate de productos.
- `merge-risk: 🚨 availability`: Los dos cron nativos desaparecen y los nuevos dispatches requieren un despliegue operativo posterior.

## Summary

Debe seguir abierta: BigQuery pasa a ser el origen por defecto aunque la rama solo espera la frescura de stocks; falta decidir y demostrar una política segura para la metadata diaria de productos.

## What This Changes

La rama migra los feeds de usado de Google Merchant a BigQuery con rollback a Mongo y reemplaza sus crons de GitHub Actions por dos dispatches de Cloud Scheduler.

## Best Possible Solution

Definir una tolerancia explícita para `mongodata.products`; hasta entonces, conservar Mongo como valor por defecto o limitar BigQuery a ejecuciones posteriores a una verificación de productos fresca.
