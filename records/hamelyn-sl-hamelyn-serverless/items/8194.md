## Summary

La rama sigue siendo necesaria y está bien orientada, pero no debe fusionarse hasta resolver la caducidad de `mongodata.products` y aportar evidencia end-to-end de los feeds y del Scheduler.

## What This Changes

La rama migra los feeds usados de Google Merchant a BigQuery, conserva Mongo como rollback y sustituye sus cron de GitHub Actions por dos dispatches de Cloud Scheduler.

## Best Possible Solution

Definir explícitamente la tolerancia comercial de metadata diaria; si no se acepta, mantener Mongo por defecto o programar Merchant tras la materialización de productos, conservando el rollback probado.
