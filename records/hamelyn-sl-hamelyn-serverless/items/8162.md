## Label Justifications

- `P1`: El flujo compartido de creación regional puede dejar listings reales en `SYNC_ERROR` y repetir una identidad incorrecta en reintentos.
- `impact:other`: Afecta a la corrección de identidad de listings regionales, sin encajar de forma precisa en las categorías de impacto más específicas.

## Summary

La incidencia sigue siendo necesaria: `dev` conserva una identidad ASIN global que puede contaminar ejecuciones regionales. La corrección local aún no está publicada como PR y requiere aprobar el contrato, el modo inicial y el rollout.

## What This Changes

Separar la resolución y el uso de ASIN/product type por marketplace para impedir que un catálogo regional reutilice la identidad global de otro.

## Best Possible Solution

Publicar una PR auditable que mantenga `legacy` por defecto, introduzca identidad regional tipada y limite el primer rollout a `shadow` en FR; `enforce` y backfill deben esperar evidencia estable.
