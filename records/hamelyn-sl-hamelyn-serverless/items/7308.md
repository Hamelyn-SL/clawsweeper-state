## Summary

Mantendría abierta la issue: `dev` no parece resolver el caso central y el código actual confirma que el withdraw de CDL no descubre ofertas vivas sin fila local `mk_casaDelLibro`/`stocks_marketplace`.

## What This Changes

Corregir la reconciliación de retiradas de Casa del Libro para retirar ofertas vivas en Mirakl cuyos stocks maestro ya están `WITHDRAWN` aunque falte la fila local `mk_casaDelLibro`/`stocks_marketplace`.

## Best Possible Solution

Añadir un recovery CDL acotado que cruce snapshot/API viva con stock maestro `WITHDRAWN`, haga dry-run verificable y siembre solo filas confirmadas como `WITHDRAWN/ACTIVE` para que el withdraw existente las retire.
