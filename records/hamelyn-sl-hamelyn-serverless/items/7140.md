## Summary

Mantengo abierta la issue: `dev` todavía no conecta el copy promocional visible con la configuración real del cupón o una fuente editable única. El `5%` citado parece quedar en un componente heredado sin uso visible, pero `PromoStrip` sigue usando textos estáticos de locales, así que el problema de fuente de verdad sigue pendiente.

## What This Changes

La issue pide que el banner/promoción visible de ecommerce derive su copy desde la configuración del cupón activo o una fuente editable única, en vez de mantener porcentajes o textos promocionales estáticos.

## Best Possible Solution

Definir una única fuente de verdad de promociones por locale que vincule cupón, fechas activas y términos estructurados, hacer que `PromoStrip` la consuma, y después retirar o reconectar `CouponBanner` para que no quede un banner heredado con copy divergente.

Question: ¿Cuál debe ser la fuente de verdad del copy promocional visible en ecommerce: datos del cupón activo, una configuración/CMS editable de promociones, o traducciones estáticas mantenidas manualmente?

Rationale: La inspección confirma la divergencia, pero cada solución cambia quién controla promociones, locales y condiciones visibles; la automatización no debería elegir ese contrato de producto.

Owner confidence: high

Options:

- **Fuente única de promociones (recommended):** Crear o reutilizar una configuración/API de promociones que referencie el cupón activo y exponga copy localizado junto con términos estructurados para `PromoStrip`.
- **Derivar desde cupones:** Construir el mensaje desde `discount.kind`, cantidades y código del cupón activo por locale, aceptando menos flexibilidad editorial.
- **Mantener copy estático:** Eliminar o deprecar el `CouponBanner` heredado y documentar que `PromoStrip` se sincroniza manualmente desde i18n, aceptando el riesgo operativo.

## Reproduction Assessment

Sí, hay reproducción de fuente por inspección: `PromoStrip` se monta en `Navbar` y lee `promoMessage`/`promoCoupon` desde JSON estático, mientras `CouponBanner` conserva `DISCOUNT = "5%"` sin uso visible encontrado. No hay reproducción live del banner del `5%`, porque el componente citado parece no estar importado actualmente.

## Solution Assessment

No está claro que haya una solución mecánica hasta decidir la fuente de verdad. La vía mantenible no es cambiar el literal `5%`, sino conectar la promo visible a una fuente única o declarar explícitamente que el copy estático seguirá siendo el contrato operativo.
