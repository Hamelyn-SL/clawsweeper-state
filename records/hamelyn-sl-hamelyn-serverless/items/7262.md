## Summary

Mantener abierta. `dev` ya tiene una recuperación parcial para `No ASIN found for this EAN`, pero esta issue trae señal fresca de producción en Amazon MX después de activar el marketplace, así que no hay evidencia suficiente para cerrarla como resuelta.

## What This Changes

La issue pide investigar los fallos de `create` de Amazon MX cuando el cron no consigue resolver un ASIN a partir del EAN.

## Best Possible Solution

Validar los SKUs recientes contra Mongo/BigQuery y, según el resultado, corregir una fuga real de cooldown o definir una política explícita de enriquecimiento, exclusión/no elegibilidad o limitación documentada para Amazon MX sin ASIN.
