## Summary

Mantener abierta. `dev` confirma la firma y el cooldown para Amazon MX, pero no resuelve la política pendiente sobre qué hacer con stocks sin ASIN resoluble.

## What This Changes

La issue reporta fallos de creación en Amazon MX cuando el cron no puede resolver un ASIN a partir del EAN.

## Best Possible Solution

Definir una política explícita para Amazon MX sin ASIN resoluble: excluir/no elegible, enriquecer antes de publicar o aceptar el retry diario ajustando la alerta.
