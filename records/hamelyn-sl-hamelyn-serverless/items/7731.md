## Summary

La incidencia sigue siendo necesaria: `dev` confirma que la lectura masiva continúa bloqueada por el proveedor y el detalle válido por SKU puede omitir `stock`, por lo que aún no existe una base segura para un snapshot o muestreo automatizado.

## What This Changes

Restablecer una lectura fiable de listings de TodoColección y, solo tras validarla, definir un muestreo dirigido para reconciliación externa.

## Best Possible Solution

Escalar el contrato de lectura con soporte de TodoColección y, tras confirmar listado y detalle por SKU, diseñar un muestreo acotado que preserve el estado ante `stock=null`.
