## Summary

Gracias por el contexto: la migración sigue siendo necesaria; ambos exports consultan `ordersells` con agregaciones MongoDB y el uso actual de BigQuery solo registra ejecuciones.

## What This Changes

Migrar `monthly-export` y `marketplace-region-export` a `hamelyn-data.mongodata.ordersells` conservando las columnas y filas actuales de los CSV.

## Best Possible Solution

Implementar consultas BigQuery con `UNNEST(products)`, validar paridad de ambos CSV y reutilizar el gate para continuar con el último snapshot BigQuery aprobado, no con MongoDB.
