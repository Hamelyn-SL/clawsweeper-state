## Summary

Gracias por el contexto: la comprobación confirmó tráfico de clientes vivos, pero `POST /cart` y `PATCH /checkout/drop-off` aún ocultan la excepción tras un 501 genérico. Mantengo esta issue abierta para que se separe el seguimiento de las causas y se priorice una corrección verificable.

## What This Changes

La issue solicita verificar si varios 501 de Public proceden de clientes activos y decidir si requieren corrección del servidor o de los clientes.

## Best Possible Solution

Añadir telemetría correlacionable a cart y drop-off, mapear sólo errores ya identificados y abrir incidencias estrechas para las causas recurrentes resultantes.
