## Label Justifications

- `P1`: El rate limit afecta a la generación de PDFs de envíos reales y reapareció después de dos mitigaciones fusionadas.
- `impact:other`: La incidencia bloquea temporalmente una operación de fulfillment relevante, pero no encaja en las categorías específicas de pérdida de datos, mensajes, sesión, autenticación o caída.

## Summary

Mantener abierta: `dev` contiene las mitigaciones de backoff y espaciado, pero la incidencia se reabrió con HTTP 429 posteriores a ambos cambios y no hay evidencia que confirme que esas entregas acabaron generando el PDF; cerrarla como implementada sería prematuro.

## What This Changes

Conseguir que la cola de etiquetas de MercadoLibre trate los HTTP 429 como recuperables mediante reintentos diferidos, sin perder trazabilidad ni dejar envíos pendientes sin PDF.

## Best Possible Solution

Mantener el backoff acotado, usar `Retry-After` cuando sea válido y registrar un desenlace terminal consultable que permita distinguir etiquetas recuperadas de mensajes agotados.
