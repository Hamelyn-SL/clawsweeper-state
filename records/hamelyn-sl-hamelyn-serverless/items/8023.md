## Summary

La PR ataca el caso observado, pero el tope fijo de `5x` solo desplaza la inanición: una racha mayor de filas stale todavía puede devolver cero seleccionados. También falta prueba real post-cambio antes de mergear.

## What This Changes

La rama amplía a `limit * 5` el pool preliminar de candidatos Amazon, conserva el límite remoto tras la revalidación maestra y registra el lote seleccionado.

## Best Possible Solution

Mantener el límite remoto configurado, pero paginar candidatos indexados hasta completar `limit` con maestros válidos o agotar la cola, con cobertura de regresión y runbook actualizado.
