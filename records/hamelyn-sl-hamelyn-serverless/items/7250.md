## Summary

Debe seguir abierta: `dev` todavía ejecuta lecturas batch intensivas contra MongoDB para flash offers, Google Merchant y el export de distribuidor. La retirada de Atlas Charts solo resolvió una parte, y el primer corte de flash offers permanece en un PR abierto sin incorporar; la issue sigue siendo útil como paraguas para coordinar y medir las migraciones restantes.

## What This Changes

Migrar las cargas batch de feeds, exports y reportes desde consultas amplias al primario de MongoDB hacia BigQuery o pools materializados con contratos explícitos de frescura.

## Best Possible Solution

Mantener esta issue como paraguas, aterrizar y medir primero flash offers, continuar con Merchant y el export, y reservar consultas live acotadas para validar cualquier mutación derivada de los reportes marketplace.
