## Summary

Gracias por el contexto: la issue sigue siendo necesaria; `dev` aún mantiene lecturas masivas contra Mongo para flash offers, Merchant y el exportador, mientras el primer corte solo está propuesto en un PR abierto y conflictivo.

## What This Changes

Migrar crons de exportación, feeds y reportes de solo lectura desde MongoDB a BigQuery para reducir la carga de CPU del primario.

## Best Possible Solution

Mantener la issue paraguas y ejecutar una migración por cortes: integrar primero flash offers, después Merchant y el exportador, con paridad, frescura y métricas operativas verificadas por flujo.
