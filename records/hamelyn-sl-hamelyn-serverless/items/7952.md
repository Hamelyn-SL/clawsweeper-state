## Label Justifications

- `P1`: Un enlace de catálogo puede mostrar resultados existentes y, tras hidratar, impedir acceder a ellos.
- `impact:ux-friction`: La pantalla contradictoria obliga al usuario a corregir manualmente la URL para continuar la búsqueda.

## Summary

La incidencia sigue vigente en `dev`: el servidor normaliza `page`, pero el cliente vuelve a convertirla sin respaldo y puede solicitar `NaN`. La PR vinculada sigue abierta y es la única vía de corrección; no procede cerrar ni duplicar trabajo.

## What This Changes

Normalizar de forma consistente los valores `page` inválidos del catálogo para conservar los resultados SSR durante la hidratación.

## Best Possible Solution

Integrar una única normalización de enteros decimales positivos y seguros en SSR, cliente, canonical y controlador, con prueba de navegador que confirme resultados y tarjetas tras hidratar.

## Solution Assessment
