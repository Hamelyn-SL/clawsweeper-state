## Summary

La PR aborda un bloqueo real del checkout, pero introduce dos regresiones de pago verificables por código: puede impedir pedidos con recogida y abre una carrera que puede duplicar la creación del checkout.

## What This Changes

La rama permite pulsar el pago con errores de formulario para marcarlos, anunciarlos y enfocar el primer dato pendiente.

## Best Possible Solution

Validar los campos según `deliveryMethod`, conservar el candado durante toda la validación asíncrona y demostrar los recorridos de domicilio, recogida y doble clic.

## Solution Assessment

No: la dirección debe ser obligatoria solo para domicilio y el candado debe cubrir también la validación; así se conserva el comportamiento de recogida y la exclusión mutua existente.
