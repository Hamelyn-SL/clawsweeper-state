## Summary

Conviene mantener este issue abierto: el código actual inicia `requeueDuplicates` y `create` en paralelo, por lo que una copia liberada puede perder la selección de creación del mismo ciclo.

## What This Changes

Corregir la carrera restante de MercadoLibre para que los candidatos liberados por duplicado se consideren antes de ejecutar la fase de creación.

## Best Possible Solution

Ejecutar `requeueDuplicates` y esperar su resultado antes de iniciar `create`, manteniendo concurrentes las fases independientes y cubriendo ese orden con una regresión focalizada.
