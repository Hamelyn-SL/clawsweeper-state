## Label Justifications

- `P1`: El cambio modifica la señal de disponibilidad de handlers cron compartidos que ejecutan trabajos operativos programados.
- `merge-risk: 🚨 compatibility`: El valor HTTP pasa de 200 a 500 para fallos totales sin una excepción por ruta ni prueba de actualización.
- `merge-risk: 🚨 availability`: Un fallo total ahora expone indisponibilidad a los planificadores y sistemas de observabilidad de todas las rutas afectadas.

## Summary

La prueba demuestra el cambio propuesto, pero convierte globalmente cualquier fallo total en HTTP 500 sin la política por ruta que exige el trabajo enlazado; además, el nuevo campo `rejectedNames` describe nombres de errores, no de métodos.

## What This Changes

La rama añade un resumen estructurado compartido para los handlers cron y responde HTTP 500 cuando todas las tareas ejecutadas rechazan.

## Best Possible Solution

Mantener el resumen estructurado, pero hacer explícita una política de severidad por ruta antes de cambiar respuestas 5xx y publicar el contrato estable para sus consumidores cron.
