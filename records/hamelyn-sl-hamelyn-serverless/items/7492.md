## What This Changes

Se solicita un panel nuevo de Trasvase que inventaríe una gaveta manual y mueva de forma trazable su contenido verificado a un BIN de Skypod.

## Best Possible Solution

Crear en `packages/core` un caso de uso de trasvase idempotente, con entidad operativa persistente, estados, eventos y recuperación; exponer una ruta Zod estrecha para estantería → BIN y construir después una vista independiente de Admin sobre ese contrato, conservando intactos los inventarios actuales.
