## Label Justifications

- `P1`: La exposición está contenida en el código actual, pero la rotación y revocación pendientes afectan credenciales usadas por automatizaciones de producción.
- `impact:security`: La incidencia trata credenciales de MongoDB y una clave privada de service account que estuvieron disponibles como variables de repositorio.

## Summary

Debe seguir abierta: el código actual ya consume únicamente `secrets.*` y la exposición por variables parece contenida, pero falta confirmar fuera del repositorio la revocación y sustitución de la clave de Drive, la retirada del acceso antiguo de Atlas y la decisión sobre los deploy hooks duplicados.

## What This Changes

La incidencia solicita completar la rotación de credenciales expuestas como variables de GitHub Actions y decidir si los deploy hooks duplicados deben mantenerse exclusivamente como secrets.

## Best Possible Solution

Un responsable con acceso a Google Cloud, Atlas y la configuración de GitHub debe revocar y recrear la clave de Drive, actualizar los secrets, ejecutar un workflow consumidor de forma controlada, comprobar que el usuario de Atlas ya no tiene acceso y retirar los hooks duplicados tras validar las integraciones externas.
