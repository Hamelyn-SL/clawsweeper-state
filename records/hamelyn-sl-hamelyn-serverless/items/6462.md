## Summary

La capacidad sigue siendo necesaria: `dev` contiene un auditor MongoDB y un sandbox específico de fulfillment, pero no ofrece una base curada anonimizada, comandos generales de creación y borrado, sincronización de índices ni detección periódica de drift. La búsqueda canónica tampoco encontró otra issue o PR que posea este trabajo.

## What This Changes

La issue solicita una base de desarrollo anonimizada y ligera, con sandboxes desechables, sincronización de índices, auditoría de drift y guardas estrictas contra producción.

## Best Possible Solution

Implementar el programa por fases: primero manifiesto e index diff estrictamente read-only, después una pipeline aprobada que construya `Hamelyn_DEV_BASE` con anonimización verificable y, por último, comandos reutilizables en `apps/local/scripts/` para crear y borrar sandboxes con allowlist, dry-run, confirmación y documentación operativa.
