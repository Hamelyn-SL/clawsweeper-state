## Summary

La iniciativa sigue siendo necesaria: `dev` solo tiene una sandbox local de fulfillment, no una base curada anonimizada ni comandos generales para crear, borrar y auditar sandboxes. El uso de datos derivados de producción exige una decisión explícita de seguridad y operación.

## What This Changes

La issue solicita una base de desarrollo ligera y anonimizada, con sandboxes desechables, sincronización de índices, detección de drift y guardas anti-producción.

## Best Possible Solution

Aprobar un diseño por fases: manifest e índices en solo lectura, sandbox con allowlist estricta y, después, una `Hamelyn_DEV_BASE` anonimizada con retención, responsables y refresh auditables.
