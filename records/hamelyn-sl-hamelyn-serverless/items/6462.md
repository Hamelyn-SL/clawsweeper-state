## Summary

La capacidad solicitada sigue siendo necesaria: `dev` contiene un auditor MongoDB y un sandbox específico de fulfillment, pero no implementa una base compartida anonimizada, comandos generales de ciclo de vida, sincronización de índices ni detección periódica de drift. No existe otra issue o PR que posea claramente este trabajo, aunque hace falta una decisión humana de seguridad antes de implementarlo.

## What This Changes

La issue solicita una base de desarrollo ligera y anonimizada, sandboxes desechables, auditoría de esquema, sincronización de índices y guardas anti-producción.

## Best Possible Solution

Definir una arquitectura por fases: primero un manifest estrictamente sin valores y guardas comunes; después creación y borrado de sandboxes desde una base ya saneada; y, en entregables separados, el pipeline restringido de refresh y anonimización, los cohorts, las fixtures y la equivalencia de índices.
