## Summary

La iniciativa sigue siendo necesaria: `dev` solo contiene una sandbox local de fulfillment, no una base curada anonimizada ni tooling general para crear, borrar, auditar y sincronizar sandboxes de desarrollo.

## What This Changes

La issue propone una base MongoDB de desarrollo anonimizada y recreable, con sandboxes desechables, sincronización de índices, detección de drift y guardas anti-producción.

## Best Possible Solution

Definir una política de datos y una arquitectura operativa aprobadas; después extraer guardas compartidas y entregar audit, creación/borrado de sandboxes e índices en fases separadas.
