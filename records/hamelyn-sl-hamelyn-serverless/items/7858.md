## Summary

La incidencia sigue siendo necesaria: `dev` conserva la configuración que hace fallar el build emitido de Core y Products aún carece de telemetría para localizar un nuevo bloqueo.

## What This Changes

## Best Possible Solution

Separar la corrección de Core de la observabilidad de Products: fijar `rootDir` y validar el build emitido, después registrar heartbeats de exportación y progreso de subida antes de reintentar el cron.
