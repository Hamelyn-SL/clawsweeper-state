The issue reports Amazon COM create failures when `/attributes/purchasable_offer` included the rejected automated-pricing rule UUID.

## Best Possible Solution

Keep the merged per-marketplace Amazon pricing-rule config path and ensure production Amazon COM config uses the accepted NA rule id.

Yes. The merged solution is narrower and more maintainable than suppressing automated pricing for Amazon COM because it sends the correct per-marketplace rule id and omits the plan when no id is configured.
