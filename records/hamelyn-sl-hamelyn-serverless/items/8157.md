## Label Justifications

- `P1`: El live-lock descrito bloquea de forma sostenida la sincronización de precios de eBay ES para stocks válidos.
- `impact:other`: El efecto concreto es una acumulación operativa en la cola de sincronización de precios de marketplace.

## Summary

La incidencia sigue siendo necesaria: `dev` mantiene la regla que clasifica este error como `STALE`, y una PR abierta vinculada contiene el arreglo específico con prueba de regresión.

## What This Changes

Clasificar los errores de actualización de precio de eBay ES sin `marketplaceId` como permanentes para que no monopolizen la cola `updatePrice`.

## Best Possible Solution

Integrar la clasificación `PERMANENT`, conservar la prueba de regresión y comprobar tras el despliegue que la cola vuelve a procesar stocks con offer ID válido.

## Solution Assessment

Sí. Cambiar la regla específica a `PERMANENT` respeta el `failureType` ya emitido y usa la exclusión de cola existente, sin añadir configuración ni rutas paralelas.
