## Summary

This should stay open: current dev has partial FEDEX multi-box and consolidated-label dedupe support, but the central automatic prep-center flow is still missing because ShipMatrix cannot match by recipient/address and FEDEX labels are still eligible for the automatic batch.

## What This Changes

The issue requests automatic FEDEX multi-box handling for heavy consolidated prep-center orders, including recipient-based routing, batch-label skipping until packing, self-service label generation, visual packing cues, and consolidation display in admin.

## Best Possible Solution

Implement this as staged fulfillment work: add validated recipient/address criteria to ShipMatrix, introduce an explicit skip/manual-packing state for configured FEDEX consolidations, then extend packing to generate or safely regenerate one shared multi-box FEDEX label PDF per consolidation.
