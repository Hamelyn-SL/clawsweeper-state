## Summary

La incidencia sigue siendo necesaria: el flujo actual convierte un HTTP 500 previo a `batch_id` en `SYNC_ERROR` reintentable para todo el lote, sin confirmar si Fnac aplicó parte de las ofertas.

## What This Changes

La incidencia solicita reconciliar lotes de actualización de precio de Fnac para evitar reintentos HTTP 500 indefinidos cuando el precio remoto ya coincide.

## Best Possible Solution

Añadir una reconciliación idempotente con una fuente autoritativa y actual de Fnac, confirmar solo las ofertas cuyo precio coincida y dejar reintentables únicamente las discrepancias verificadas.

## Solution Assessment

No del todo: reconciliar es el enfoque correcto, pero debe basarse en un estado actual y autoritativo de Fnac, no únicamente en un snapshot con antigüedad conocida.
