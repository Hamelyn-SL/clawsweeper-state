## Summary

La incidencia sigue siendo necesaria: `dev` aún persiste el fallo batch de precio como `SYNC_ERROR` y no ejecuta recuperación específica de `UPDATING_PRICE` para Fnac. La solución candidata sigue abierta en https://github.com/Hamelyn-SL/hamelyn-serverless/pull/7809.

## What This Changes

Evitar que errores HTTP 500 transitorios de Fnac dejen ofertas activas bloqueadas en reintentos indefinidos de actualización de precios.

## Best Possible Solution

Integrar, tras prueba real del cron y confirmación de batch Fnac, una recuperación limitada a precios que rote errores transitorios sin considerar un HTTP 500 como confirmación remota.
