## Summary

Debe seguir abierta: `dev` conserva y normaliza el CP de Postlibri, pero no contiene el catálogo ni un lookup de oficinas; la correspondencia CP→oficina requiere confirmación operativa de Correos.

## What This Changes

La solicitud propone cargar oficinas de Correos por código postal y mostrarlas para incidencias de pedidos Postlibri.

## Best Possible Solution

Tras la confirmación de Correos, crear un catálogo versionado indexado por CP y un lookup derivado en Admin para `POSTLIBRI`, con estado explícito cuando no haya oficina confirmada.
