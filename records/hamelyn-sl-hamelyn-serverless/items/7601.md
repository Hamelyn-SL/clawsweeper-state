## Summary

Debe seguir abierta: `dev` no carga el catálogo adjunto ni resuelve una oficina de Correos para un pedido `POSTLIBRI`, y antes de implementar falta confirmar que la igualdad de código postal identifica realmente la oficina de recogida aplicable.

## What This Changes

Añadir un catálogo de oficinas de Correos y una consulta por código postal del cliente para que Atención al Cliente pueda indicar la oficina asociada a pedidos `POSTLIBRI` no entregados.

## Best Possible Solution

Tras validar la correspondencia con Correos, incorporar un catálogo versionado de oficinas aplicable a Postlibri, con cobertura y fecha de actualización explícitas, y mostrar un lookup derivado en el detalle de Admin sin copiarlo en cada pedido.
