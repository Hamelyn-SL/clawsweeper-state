## Summary

Debe seguir abierto: el cambio documenta una mejora útil para evitar que los watchers silencien incidencias activas con fixes abandonados, pero el head actual introduce un comando de GitHub inválido que rompe justo la ruta de estancamiento que pretende habilitar.

## What This Changes

El PR actualiza las guías de `issue-triage`, `marketplace-watcher`, `crons-watcher` y formato de comentarios para añadir reencolado por `phase=staleness`, fast-exit seco e integridad del cuerpo publicado.

## Best Possible Solution

Mantener la idea de `phase=staleness`, pero sustituir el check por una consulta válida de GitHub para timeline/cross-references o por campos soportados, y añadir prueba real del comando que usarán los watchers.
