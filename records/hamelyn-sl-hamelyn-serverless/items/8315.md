## Label Justifications

- `P2`: Es una mejora de rendimiento amplia y valiosa, pero no hay evidencia de pérdida de datos, caída o bloqueo completo del flujo de compra.
- `impact:ux-friction`: El render dinámico de las rutas públicas añade latencia y elimina parte del beneficio de navegación instantánea esperado.

## Summary

La migración sigue siendo necesaria: `dev` usa Next 16.3, pero no activa Cache Components y el layout raíz conserva dependencias por petición que impiden una caché de shell global segura.

## What This Changes

Migrar Ecommerce a Cache Components de Next 16.3 para acelerar las navegaciones públicas, preservando locale, stock, precios, promociones y variantes dependientes de cada visitante.

## Best Possible Solution

Definir una matriz de segmentos cacheables y dinámicos, migrar por fases el shell, catálogo/PDP y rutas autenticadas, y aceptar solo tras pruebas de preview para los 13 storefronts y datos vivos.

## Solution Assessment
