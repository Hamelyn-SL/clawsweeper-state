## Summary

La issue sigue siendo necesaria: `dev` no activa Cache Components y el layout raíz aún depende de `headers()`. La implementación está representada por una PR abierta que declara cerrar este trabajo, por lo que esta issue debe permanecer abierta hasta revisar y aterrizar esa PR.

## What This Changes

Migrar Ecommerce a Cache Components de Next 16.3 para prerenderizar shells, transmitir contenido dinámico y acelerar las navegaciones no-API.

## Best Possible Solution

Revisar y fusionar de forma segura https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8316, verificando en preview las invariantes de los 13 storefronts antes de que GitHub cierre esta issue.
