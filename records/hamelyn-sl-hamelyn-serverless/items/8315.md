## Summary

La necesidad sigue vigente en `dev`: Cache Components no está activado y el layout raíz aún bloquea el shell con datos de request. Ya existe una PR abierta que declara resolver este alcance, pero continúa con cambios solicitados; cerrar esta issue antes de integrarla duplicaría el cierre.

## What This Changes

Migrar `apps/hamelyn-ecommerce` a Cache Components de Next 16.3 para prerenderizar shells de rutas y mantener dinámicos locale, precio, stock, promociones y experimentos por visitante.

## Best Possible Solution

Integrar una migración por fases que aísle los datos de request detrás de `Suspense`, conserve precio, stock y variantes por visitante en vivo, y valide cada storefront con pruebas de ruta y preview.
