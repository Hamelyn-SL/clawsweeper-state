## Summary

Mantener abierta: el selector de runtime ya limita el recovery a errores recuperables `TRANSIENT`, y la señal de inanición procede de una métrica amplia del watcher. La PR abierta https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8166 corrige esa clasificación.

## What This Changes

Aclarar que la métrica FIFO de recuperación de precio de Amazon MX debe usar el selector accionable real, no el agregado amplio de `SYNC_ERROR`.

## Best Possible Solution

Revisar y fusionar la PR vinculada para que el watcher mida el mismo pool accionable que consume el runtime y reporte la deuda `UNKNOWN` por separado.

## Solution Assessment
