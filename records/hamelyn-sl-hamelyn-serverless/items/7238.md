## Label Justifications

- `P1`: Es un deploy a producción bloqueado por una superficie de agente/cron sensible y por validación operativa incompleta.
- `merge-risk: 🚨 compatibility`: El merge `dev` → `master` cambia varios dominios productivos y una app nueva con configuración/envs propios.

## Summary

Debe seguir abierta: esta PR es el release `dev` → `master`, pero aún tiene un bloqueo de seguridad/operación en `apps/agents` y no aporta prueba real del bundle completo antes de producción.

## What This Changes

Esta PR promueve `dev` a `master` para desplegar a producción 15 PRs ya mergeadas, incluyendo cambios en ecommerce, marketplace-crons, data-platform, Slack/GitHub automation y la nueva app `apps/agents`.

## Best Possible Solution

Antes de mergear a `master`, proteger los crons de `apps/agents` con `CRON_SECRET`/bearer o una validación equivalente, aportar logs redaccionados de deploy/cron y confirmar que los proyectos Vercel críticos están verdes.
