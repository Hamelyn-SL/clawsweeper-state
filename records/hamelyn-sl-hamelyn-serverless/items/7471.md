## Label Justifications

- `P2`: Es un bug operativo reproducible y acotado a pedidos ecommerce sin stock suficiente, sin evidencia de bloqueo total, pérdida de pedidos o indisponibilidad.
- `impact:ux-friction`: El marcador técnico sustituye el título legible y dificulta identificar rápidamente los productos que deben cancelarse o reembolsarse.

## Summary

La issue sigue siendo necesaria: el comportamiento descrito permanece en `dev` y las capturas coinciden exactamente con el camino actual que guarda un marcador técnico como título visible del producto. No existe otra issue o PR abierto que esté corrigiendo este defecto.

## What This Changes

Corregir los pedidos ecommerce `TO_CANCEL` para que Admin muestre el título o referencia normal del producto en vez de `[REEMBOLSO PENDIENTE] <EAN>`.

## Best Possible Solution

Conservar el título canónico del carrito al agrupar productos y usarlo en el placeholder, manteniendo `REFUND_PARTIAL_*` como señal técnica separada; además, aplicar una corrección dirigida o un fallback de lectura para que los pedidos ya afectados también muestren una referencia legible.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, desde código con alta confianza. Un checkout que solicita más unidades que el stock disponible crea un placeholder `REFUND_PARTIAL_*`, genera un `OrderSell` `TO_CANCEL` y Admin muestra literalmente su `title`; no se ejecutó el flujo contra una base de datos real durante esta revisión de solo lectura.

## Solution Assessment

No sería suficiente limpiar el texto únicamente en la tabla. La solución mantenible es conservar el título canónico en el modelo persistido, mantener el estado técnico en el identificador del placeholder y contemplar los registros existentes.
