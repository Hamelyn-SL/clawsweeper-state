## Summary

Mantener abierta: `internal_error` ya se recupera, pero la variante reabierta `shipping.default.error` no coincide con la política ni con el regex de recuperación actuales.

## What This Changes

Resolver los fallos de creación de MercadoLibre ligados a errores de envío para que los casos realmente transitorios se recuperen sin reintentos ciegos.

## Best Possible Solution

Capturar una muestra redacted del error reabierto y, si confirma un fallo temporal, añadir una regla estrecha con prueba de clasificación y recuperación.
