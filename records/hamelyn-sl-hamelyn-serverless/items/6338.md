## Summary

Mantener abierta: la corrección fusionada cubre el `internal_error` original, pero la variante reabierta `shipping.default.error` no está contemplada por el clasificador ni por la selección de recovery actuales.

## What This Changes

La incidencia solicita que los errores transitorios de shipping durante `create` en MercadoLibre se recuperen sin dejar SKUs en `SYNC_ERROR`.

## Best Possible Solution

Confirmar con muestras redactedas el código HTTP y payload completo de `shipping.default.error`; si es un 5xx transitorio, ampliar de forma acotada las reglas y añadir regresión para clasificación y recovery.

No hay una reproducción actual de alta confianza contra MercadoLibre. El código permite comprobar que la firma reabierta no coincide con las reglas actuales, pero falta una muestra completa para decidir su semántica.

## Solution Assessment

No del todo: ampliar la regla sin confirmar el payload podría ocultar un error permanente. La vía más mantenible es clasificar solo la variante demostrada como transitoria y cubrirla con pruebas.
