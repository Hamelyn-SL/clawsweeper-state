## Summary

## What This Changes

La PR migra los watchers de errores de Marketplace y Crons desde Lyno a schedules Eve/Vercel con precheck determinista, estado Blob y acciones GitHub restringidas.

Mantener la migración en esta PR, pero introducir una puerta de activación persistente tras la importación verificada, hacer fail-closed las lecturas de GitHub y corregir la paginación, el filtrado y las etiquetas antes de habilitar los schedules productivos.
