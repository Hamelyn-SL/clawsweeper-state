## Summary

Conviene mantener este PR abierto: el endurecimiento del triage y la corrección de Fixer son útiles, pero el head actual convierte una cola sana sin alertas en un fallo del workflow y todavía no aporta prueba real de una ejecución completa.

## What This Changes

El PR añade un contrato JSON y un gate para el triage de Dependabot, actualiza su skill y estrecha la respuesta de Fixer API para recuperar la build de `@hamelyn/core` y `@hamelyn/ui`.

## Best Possible Solution

Dejar un contrato único que represente explícitamente la cola vacía, valide el número de alertas realmente vistas y produzca avisos seguros; conservar el estrechamiento de Fixer con build verificada, prueba real del workflow y un cuerpo de PR sin atribuciones automáticas.
