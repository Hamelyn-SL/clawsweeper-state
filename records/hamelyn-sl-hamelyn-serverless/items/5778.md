## Summary

Keep open: the merged partial fix covers the original `Cannot revise listing` retry classification, but the issue was reopened with live `bulk_create_or_replace_inventory_item` account/policy variants that current `dev` does not clearly classify as permanent or transient.

## What This Changes

The issue asks marketplace-crons to stop repeatedly retrying eBay create rejections caused by title/description policy, account limits, or seller-policy blocks.

## Best Possible Solution

Split the reopened eBay create failures by cause: product/content-policy rejections should become permanent per SKU, while account-limited seller blocks should trigger an account-level operational signal and a deliberate requeue path after resolution.
