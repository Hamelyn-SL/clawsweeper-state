## Summary

La corrección fusionada cubre `Cannot revise listing`, pero las variantes reaparecidas de bloqueo de cuenta y política no tienen una regla explícita ni una recuperación acordada; esta incidencia sigue siendo necesaria.

## What This Changes

Clasificar los rechazos de creación de eBay por política para evitar reintentos automáticos improductivos y conservar una recuperación operativa adecuada.

## Best Possible Solution

Separar reglas terminales de política de contenido de restricciones recuperables de cuenta, añadir pruebas por firma y reactivar create solo con una señal operativa acordada.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Qué política de recuperación debe aplicarse a los bloqueos de cuenta de eBay frente a los rechazos permanentes de contenido?

Rationale: El código puede reconocer mensajes concretos, pero decidir si una cuenta limitada se reencola manualmente o conserva recuperación automática es una elección operativa.

Likely owner: JavierHamelyn

Owner reason: Su cambio controla actualmente la reactivación del flujo create y la decisión afecta directamente a esa contención.

Owner confidence: high

Options:

- **Separar causa terminal y bloqueo recuperable (recommended):** Marcar solo las políticas de contenido confirmadas como `PERMANENT` y exigir reencolado explícito para bloqueos de cuenta resueltos.
- **Tratar toda restricción como permanente:** Elimina reintentos, pero asume que toda recuperación se gestionará manualmente fuera del cron.
- **Conservar reintentos para bloqueos de cuenta:** Permite recuperación automática, pero mantiene carga mientras la cuenta continúe limitada.

## Reproduction Assessment

No para producción actual: `ebay.create()` está deshabilitado. Sí existe una ruta clara desde código al reactivarlo, y las firmas nuevas no coinciden con ninguna regla explícita.

## Solution Assessment

No del todo: la regla actual resuelve la firma original, pero no distingue las causas de política permanente de una limitación de cuenta potencialmente recuperable.
