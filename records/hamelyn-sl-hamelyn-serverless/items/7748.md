- `impact:other`: El impacto es operativo en la automatización de Marketplace y no encaja en una clase más específica.

## Summary

Gracias por el contexto: el defecto sigue presente en `dev` y la sincronización programada continúa dependiendo de una hora de inicio que GitHub Actions no garantiza.

## What This Changes

La incidencia pide eliminar el no-op horario que impide ejecutar automáticamente la sincronización diaria de devoluciones pendientes de Amazon.

## Best Possible Solution

Usar un único tick diario a las 05:00 UTC y ejecutar siempre el proceso solicitado, sin condicionar la sincronización al reloj real del runner.
