## Summary

This issue should stay open: current dev still accepts notify signups without product-existence validation and the daily cron still skips missing products without marking those requests terminal. The linked closing PR is open and unmerged, so it should remain the implementation path rather than closing the issue early.

## What This Changes

The issue requests validation or cleanup for ecommerce availability-notify records whose EAN does not exist in the product catalog.

## Best Possible Solution

Land one maintainer-approved fix PR that makes signup validation and missing-product cron handling match the accepted BL rule, then let the issue close from the merged PR.
