## Summary

El PR conserva una propuesta útil, pero no debe integrarse aún: interpreta señales de autor ausentes como demanda baja pese a una cobertura medida del 35,5%, y además pierde el fallback de rango entre Amazon ES y COM.

## What This Changes

El PR añade un filtro de demanda no probada para productos nuevos, persiste señales de Amazon/editorial/autor y programa su sincronización mensual.

## Best Possible Solution

Definir que una señal no medida no equivale a un ratio bajo, elevar la cobertura al universo del backtest o excluir esas filas, y extraer el primer rango válido entre ES y COM antes de activar el filtro.
