## Label Justifications

- `P1`: La creación de ofertas de eBay permanece detenida y afecta a un flujo de marketplace operativo.
- `impact:other`: El impacto es la indisponibilidad de publicación y observabilidad operativa de eBay, fuera de las categorías específicas disponibles.

## Summary

Mantener abierta: la creación de eBay sigue pausada y, al reactivarla, `bulkPublishOffer` aún acepta lotes fallidos sin elevar una señal operativa compatible.

## What This Changes

La incidencia solicita que los rechazos de `bulkPublishOffer` no se oculten tras una respuesta HTTP correcta del cron de eBay.

## Best Possible Solution

Definir una señal estructurada y compatible para fallos de publicación, validarla en una cohorte limitada y reactivar `ebay.create()` con criterio explícito de reversión.

- **Cambiar el handler global:** Modificar la semántica compartida de fallos parciales antes de reactivar eBay, asumiendo el impacto en otras rutas.
