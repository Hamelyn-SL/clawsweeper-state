## Label Justifications

- `P1`: La publicación de nuevas ofertas de eBay está desactivada como mitigación y el comportamiento pendiente afecta de forma sostenida a la sincronización de marketplace.
- `impact:other`: La incidencia afecta la observabilidad y la continuidad operativa del cron de marketplace, sin encajar con mayor precisión en las categorías de impacto disponibles.

## Summary

Mantener abierta: `dev` evita temporalmente que el cron ejecute `ebay.create()`, pero el código de publicación aún acepta la respuesta parcial de `bulkPublishOffer` y el handler compartido sigue devolviendo HTTP 200 ante rechazos parciales. La clasificación ya fusionada para una causa concreta de política reduce reintentos inútiles, pero no decide ni resuelve la reactivación segura de create ni la señal operativa general.

## What This Changes

La incidencia solicita que los fallos de publicación de ofertas de eBay mediante `bulkPublishOffer` no queden ocultos como una ejecución sana del cron.

## Best Possible Solution

Definir en https://github.com/Hamelyn-SL/hamelyn-serverless/issues/5622 la severidad y la señal estructurada para fallos parciales, conservar la clasificación permanente conocida y preparar una reactivación acotada de `ebay.create()` con telemetría por `offerId`, causas remotas y prueba real contra eBay antes de habilitarla.
