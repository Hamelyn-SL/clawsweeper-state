## Label Justifications

- `P1`: La publicación de ofertas eBay permanece deshabilitada y su reactivación depende de resolver una incidencia de sincronización activa.
- `impact:other`: El impacto principal es operativo: lotes de catálogo no publicados y señal de salud del cron insuficiente.

## Summary

Mantener abierta: `dev` desactiva temporalmente la fase `create`, pero conserva tanto el manejo parcial de `bulkPublishOffer` como la respuesta HTTP 200 del handler; falta decidir la señal operativa y la reactivación segura.

## What This Changes

La incidencia pide evitar que rechazos de publicación eBay en `bulkPublishOffer` queden absorbidos por el cron como éxito global.

## Best Possible Solution

Definir el contrato operativo para fallos completos de publicación, registrar el detalle remoto por oferta y validar contra eBay antes de reactivar `ebay.create()`.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Debe un lote eBay con cero publicaciones correctas fallar operativamente el cron o mantener HTTP 200 con una alerta/telemetría obligatoria antes de reactivar `create`?

Rationale: El código actual permite ambos comportamientos y la elección afecta al contrato de monitorización y a la tolerancia de otras fases parcialmente recuperables.

Likely owner: JavierHamelyn

Owner reason: Su cambio actual introdujo la pausa temporal y documenta la condición para reactivar el flujo.

Owner confidence: high

Options:

- **Señal específica sin cambiar HTTP (recommended):** Mantener HTTP 200, pero emitir una alerta estructurada y visible cuando `bulkPublishOffer` complete un lote con cero éxitos antes de reactivar create.
- **Fallar el cron en publicación total:** Propagar como error operativo un lote de publicación totalmente fallido, aceptando que el endpoint deje de responder 200 en ese caso.
- **Mantener la pausa:** Conservar create deshabilitado hasta aislar todas las causas remotas y acordar el comportamiento de monitorización.

## Reproduction Assessment

No en producción actual: `ebay.create()` está deshabilitado. Sí hay una ruta reproducible desde código al reactivarla, con respuestas parciales que el handler resume como HTTP 200.

## Solution Assessment

Incierto: mejorar el detalle por oferta es el camino más estrecho, pero la severidad HTTP/alerta requiere una decisión operativa antes de cambiar el contrato.
