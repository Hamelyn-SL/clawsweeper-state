## Summary

Mantener abierta: el problema sigue siendo necesario porque el cron actual solo reenvía retiradas maestras recientes y no reconcilia listings comprables antiguos sin `mk_amazonEs`.

## What This Changes

Añadir una recuperación recurrente para listings de Amazon ES retirados que permanecen comprables cuando ya no existe su fila `mk_amazonEs`.

## Best Possible Solution

Incorporar una reconciliación diaria snapshot→Mongo para candidatos confirmados y reutilizar el withdraw canónico; reservar SP-API directo para SKUs sin documento maestro.
