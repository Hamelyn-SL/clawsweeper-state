## Summary

Mantener abierta: `dev` todavía puede leer la configuración `DEV` de Amazon COM y reproducir el fallo LWA 401; la corrección específica sigue en una PR abierta que ahora tiene conflictos con cambios posteriores del mismo helper.

## What This Changes

Hacer que la validación read-only de Amazon COM use siempre la configuración `PROD` y permita sustituir `sellerId` a partir de `merchantId`.

## Best Possible Solution

Reaplicar el filtro `{ name, environment: "PROD" }` y el alias `sellerId` sobre el helper actual, conservar la política de caché de MercadoLibre y demostrar una llamada read-only 200 de Amazon COM junto con una comprobación segura del filtro de rotación de MercadoLibre.
