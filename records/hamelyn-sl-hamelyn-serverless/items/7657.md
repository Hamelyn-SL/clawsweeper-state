## Summary

El PR debe seguir abierto: la dirección del checkout autenticado es sólida, pero el nuevo contrato automatizable publica JSON inválido cuando el texto contiene caracteres angulares y la evidencia disponible no demuestra todo el comportamiento del head actual.

## What This Changes

El PR sustituye `GIT_ASKPASS` por credenciales inyectadas temporalmente mediante la política de red de Vercel Sandbox, añade estados estructurados de prueba y publica planes de desbloqueo automatizables.

## Best Possible Solution

Mantener el brokering temporal limitado a `github.com`, serializar un bloque JSON realmente parseable y conservar prueba E2E saneada del checkout head/base y de la retirada de la credencial antes de ejecutar la rama.
