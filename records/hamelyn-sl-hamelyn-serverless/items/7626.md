## Summary

La issue sigue siendo necesaria: el 16 de julio de 2026 el fallo se reproduce en la web pública y el código actual de `dev` mantiene la configuración que reduce el viewport interno del carrusel al ancho de una sola tarjeta.

## What This Changes

Corregir el carrusel «más populares» de las páginas de venta para que distribuya los productos por todo el ancho disponible en móvil y escritorio.

## Best Possible Solution

Separar en web el ancho total del viewport del ancho individual de tarjeta —preferiblemente recuperando una lista horizontal web o usando un carrusel que admita ambos valores— y conservar sin cambios el comportamiento nativo, con prueba visual responsive en las cuatro páginas de categoría.
