## Label Justifications

- `P1`: La ruta de producción puede quedar indisponible durante 800 segundos y terminar en 504 de forma recurrente.
- `impact:crash-loop`: El runtime queda retenido hasta el límite duro de Vercel, afectando la disponibilidad operativa del cron.

## Summary

Debe mantenerse abierta: la conexión Mongo ya está acotada, pero Amazon COM sigue esperando todas las fases sin un límite por fase; además, la firma de 800 segundos reapareció en producción tras la normalización previa.

## What This Changes

Investigar y evitar que el cron `/api/amazonCOM` consuma los 800 segundos de Vercel cuando una fase queda bloqueada.

## Best Possible Solution

Usar las trazas de fase ya presentes para identificar la operación retenida y añadir una salida acotada con tratamiento explícito de reintento, sin volver a duplicar guards por ruta.

## Maintainer Decision

Required: true

Kind: product_direction

Question: ¿Qué política debe aplicarse cuando una fase Amazon COM supera un presupuesto operativo: abortar todo el run, aislar la fase y continuar, o reintentarla de forma diferida?

Rationale: El código permite medir la fase retenida, pero decidir cómo preservar la coherencia de operaciones parcialmente completadas requiere criterio operativo.

Likely owner: JavierHamelyn

Owner reason: Su trabajo previo fijó la frontera entre guards de ruta y la capa común de conexión y cron.

Owner confidence: high

Options:

- **Instrumentar antes de limitar (recommended):** Capturar una nueva ocurrencia con la fase exacta y diseñar el límite y reintento sobre esa operación.
- **Abortar el run al exceder presupuesto:** Aplicar un deadline global o por fase y devolver un fallo controlado para reintento posterior.
- **Aislar fases no críticas:** Permitir que las demás fases concluyan y registrar la fase vencida para recuperación dirigida.

## Reproduction Assessment

No tenemos una reproducción actual de alta confianza: los logs de producción confirman el síntoma, y el código muestra la espera sin deadline, pero falta capturar qué fase permanece retenida.

## Solution Assessment

No está resuelto aún: normalizar las rutas y acotar Mongo fue correcto, pero no limita las operaciones posteriores que pueden agotar los 800 segundos.
