## Label Justifications

- `P1`: La cancelación deja bloqueado un flujo operativo de pedidos de venta en Admin hasta que el usuario encuentra una salida alternativa.
- `impact:ux-friction`: La interfaz confirma el cambio de estado pero no lleva al usuario de vuelta a su lista de trabajo.

## Summary

Gracias por el reporte. El flujo actual confirma que, al cancelar desde la edición, se actualiza el estado y solo se refresca el registro; la ruta sigue siendo la del pedido cancelado. Esta issue sigue siendo necesaria y tiene una reparación acotada.

## What This Changes

Corregir la cancelación desde la edición de un pedido de venta para volver a la lista operativa en lugar de permanecer en el pedido cancelado.

## Best Possible Solution

Tras una cancelación correcta desde la edición, navegar a la lista de pedidos de venta y conservar el refresco necesario para que no quede visible el registro ya cancelado.
