## Label Justifications

- `P1`: La señal de rastreo afecta a millones de URLs y el serving puede fallar bajo solicitudes paralelas, pero no hay evidencia de una caída total del ecommerce.
- `impact:other`: El impacto concreto es SEO, indexación y consumo de infraestructura; no encaja de forma más precisa en la taxonomía disponible.

## Summary

La issue sigue siendo necesaria: `dev` publica `lastmod` desde `mongodata.products.timestamp` y las hojas públicas aún pasan por handlers que resuelven el manifiesto y descargan Blob, con una caché de una hora.

## What This Changes

Corregir el `lastmod` de producto para que refleje cambios SEO significativos y servir las hojas del sitemap desde CDN con caché prolongada o estática.

## Best Possible Solution

Persistir una señal SEO semántica con precio y disponibilidad de referencia, materializarla para el generador y servir manifiestos y hojas mediante CDN con `s-maxage=21600`, una semana stale y pre-warm posterior.
