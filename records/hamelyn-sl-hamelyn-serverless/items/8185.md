## Summary

La integración de MercadoLibre ya está activa, pero no existe un puente con eDesk; concretar el flujo operativo y la propiedad de credenciales requiere una decisión de producto antes de implementarlo.

## What This Changes

La petición propone conectar las APIs de MercadoLibre y eDesk para gestionar ese marketplace desde la plataforma.

## Best Possible Solution

Definir el flujo de negocio y el dueño de cada dato; después añadir una integración acotada con canal eDesk propio, secretos configurados y sincronización idempotente.

- **Diseñar sincronización completa:** Abrir una iniciativa separada para pedidos, estados y mensajería con contratos de idempotencia y conciliación.
