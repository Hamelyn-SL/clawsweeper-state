## Summary

La integración de Mercado Libre ya está activa, pero no existe una conexión con eDesk para ese marketplace; la petición sigue siendo necesaria y requiere concretar el flujo de soporte antes de implementarla.

## What This Changes

La issue solicita conectar Mercado Libre con eDesk para gestionar incidencias o conversaciones de ese marketplace desde la plataforma.

## Best Possible Solution

Definir un contrato de integración limitado —eventos de entrada, creación o enlace de tickets, canal de eDesk, deduplicación y operación ante fallos— antes de añadir configuración y colas específicas.
