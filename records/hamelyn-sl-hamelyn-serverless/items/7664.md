## Label Justifications

- `P1`: La monitorización local quedó pausada y no existe aún cobertura automática equivalente para detectar nuevas firmas de errores operativos.

## Summary

Debe seguir abierta: `dev` solo contiene patrones reutilizables de precheck y persistencia, pero aún faltan los dos schedules, el registro específico, las operaciones GitHub, la importación y el corte operativo; tampoco hay una PR vinculada que asuma el trabajo.

## What This Changes

Migrar Marketplace Watcher y Crons Watcher desde automatizaciones locales pausadas a dos schedules Eve con precheck determinista, estado idempotente, integración GitHub y corte controlado.

## Best Possible Solution

Implementar el corte por fases: motor determinista y fixtures compartidos, store Zod idempotente, adapter GitHub fail-closed, schedules en dry-run, importación one-shot no versionada y activación con una semana de observación antes de retirar las automatizaciones locales.
