## Label Justifications

- `P2`: La explotación depende de ejecutar un script manual, pero este procesa contenido externo dentro de un entorno con acceso y credenciales de producción.
- `impact:security`: La vulnerabilidad puede causar corrupción de memoria, caída o posible ejecución de código al decodificar un PSD manipulado.

## Summary

La alerta sigue siendo necesaria porque `dev` aún fija una versión vulnerable y el PR candidato permanece abierto; el código actual permite que contenido externo active el decodificador PSD afectado.

## What This Changes

Actualizar Pillow a `12.2.0` o superior para corregir el integer overflow de tile extents PSD alcanzable desde el script manual de migración de imágenes.

## Best Possible Solution

Mantener un único pin en `Pillow==12.2.0` y demostrar en un entorno controlado que `analyze_image()`, `get_image_embedding()` y `convert_to_webp()` siguen funcionando con un producto de prueba antes de incorporar el cambio a `dev`.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, a nivel de fuente con alta confianza: `Pillow==10.4.0` está afectado y tres funciones pasan bytes procedentes de URLs de producto a `Image.open()` sin limitar formatos. No se ejecutó un PSD malicioso porque la inspección estática ya demuestra el vector y evita una prueba destructiva innecesaria.

## Solution Assessment

Sí en cuanto a implementación: elevar el único pin compartido a `12.2.0` es la reparación mínima y cubre esta alerta junto con los advisories relacionados. La solución debe completarse con una prueba operativa del script, que el PR candidato todavía no aporta.
