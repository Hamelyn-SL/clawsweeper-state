Full review comments:

- **[P1] Serializa el refresh del token de Codex:** `apps/agents/agent/lib/codex-token.ts:193-194`
  - body: `getAccessToken()` y el cron `refreshIfNeeded()` pueden leer el mismo token del Blob y llamar a `refresh()` en paralelo. Como el `refresh_token` es single-use, una carrera puede dejar persistido un token inválido y tumbar todos los agentes hasta intervención manual; hace falta lock/CAS o un único refrescador distribuido.
  - confidence: 0.93
- **[P1] Aísla mongo_script fuera del runtime de la app:** `apps/agents/agent/tools/mongo_script.ts:110-114`
  - body: El script aprobado se ejecuta con `new Function()` dentro del proceso web, con acceso a globales como `process.env` y `fetch`; además `Promise.race()` no cancela trabajo async ya lanzado ni bucles síncronos. Para una herramienta con Mongo write en producción, la aprobación humana debe ir acompañada de aislamiento técnico, por ejemplo worker/proceso terminable o un DSL de operaciones acotadas.
  - confidence: 0.95
- **[P1] Coordina el refresh compartido de MercadoLibre:** `apps/agents/agent/lib/meli-client.ts:52-56`
  - body: Esta app añade otro consumidor que refresca y escribe `config.mercadolibre.data.refreshToken` directamente. Ese token es single-use y core ya trata carreras intra-proceso con `refreshTokenPromise`; sin lock/CAS compartido o reutilizar el cliente de core, un heartbeat/agente puede invalidar el cron de precios de producción.
  - confidence: 0.87
- **[P2] Tolera reviews sin usuario en el asignador:** `apps/agents/agent/pr-reviewer/github.ts:129-131`
  - body: GitHub puede devolver reviews con `user: null` cuando una cuenta se elimina o queda inaccesible. El acceso directo a `r.user.login` rompe `fetchPrSnapshot()`, y entonces el reviewer bot deja de asignar justo en PRs que intenta gestionar.

  - body: El schema pide exactamente `targetReviewers`, pero después se filtran logins inválidos y se devuelve `valid.slice(0, targetReviewers)` aunque quede solo uno. En PRs grandes configurados para dos reviewers, el bot puede publicar una asignación incompleta sin error.
