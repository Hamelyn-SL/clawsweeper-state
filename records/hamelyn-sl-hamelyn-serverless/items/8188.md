## Summary

La incidencia sigue siendo necesaria: `dev` clasifica primero errores de precio Amazon como `TRANSIENT` y no protege `101078`, por lo que un bundle mixto puede entrar en recovery automático.

## What This Changes

La incidencia pide bloquear el recovery automático de Amazon para `101078` y diseñar una remediación segura de condiciones inconsistentes entre regiones.

## Best Possible Solution

Aterrizar primero una PR pequeña que fuerce `101078 → UNKNOWN` antes de reglas de precio y cubra las seis regiones; después diseñar separadamente el resolver con preimagen account-wide, preview y aprobación previa al backfill.
