## Label Justifications

- `P2`: El defecto bloquea el escaneo de algunas etiquetas multibulto MRW, pero está acotado a un flujo de packing concreto y ya tiene una corrección candidata.
- `impact:other`: La etiqueta resultante no se puede picar en la operación de almacén; es un impacto operativo concreto fuera de las categorías especializadas.

## Summary

La incidencia sigue vigente en `dev`: el flujo multibulto aún envía el peso con punto decimal. La PR enlazada propone el ajuste exacto y usa cierre automático, pero permanece abierta, por lo que esta incidencia debe seguir abierta hasta su integración.

## What This Changes

Corregir la serialización del peso de los envíos multibulto MRW para que SAGEC reciba decimales con coma y genere etiquetas escaneables.

## Best Possible Solution

Integrar la normalización con coma en el límite hacia SAGEC, validar una etiqueta multibulto controlada y dejar el cálculo de peso compartido sin cambios.

## Maintainer Decision

Required: false

## Reproduction Assessment

Sí, desde código hay una ruta de alta confianza: 26 productos y 2 bultos calculan 10,4 kg y el `dev` actual lo serializa como `10.40` antes de llamar a MRW.

## Solution Assessment

Sí, normalizar el decimal en el campo `peso` justo antes de SAGEC es el cambio más estrecho; no altera la política compartida de cálculo ni otros carriers.
