## Summary

La propuesta aborda un fallo real de PR Proof, pero conserva bloqueos de recuperación, notificaciones y elegibilidad que impedirían operar el nuevo gate con seguridad.

## What This Changes

La PR migra PR Proof a un controlador v2 autoritativo con polling vinculado a SHA, reconciliación del body y publicación dedicada del check `proof-evidence`.

## Best Possible Solution

Mantener el gate v2, restaurar una reejecución segura para PRs abiertas, alinear elegibilidad y consumidores del evento, actualizar las guías operativas y demostrar el flujo completo desde GitHub Actions.
