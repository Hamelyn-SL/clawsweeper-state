## Label Justifications

- `P1`: La causa activa genera miles de errores y puede detener el procesamiento de imágenes cuando Serper devuelve un `400`.
- `impact:security`: El adaptador registra el `AxiosError` completo y el triage identifica posible exposición de cabeceras sensibles.
- `impact:other`: El consumo de créditos y el ruido masivo en logs degradan la operación sin encajar en otra taxonomía específica.

## Summary

Se mantiene abierta: el PR enlazado cubre el guard defensivo, pero la evidencia de producción atribuye la firma principal a falta de créditos y siguen pendientes el saneo del error y la clasificación segura del `400`.

## What This Changes

La incidencia pide evitar consultas vacías a Serper y evitar que un `400` interrumpa por completo el cron de imágenes.

## Best Possible Solution

Rotar y recargar la credencial de Serper, registrar sólo datos saneados y abortar el lote únicamente cuando la respuesta confirme falta de créditos; conservar el guard de consultas vacías como defensa adicional.
