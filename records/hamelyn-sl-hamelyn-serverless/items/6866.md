## Summary

La revisión confirma que el PR relacionado cubrió dos hallazgos con tests y mejoró EPIPE, pero el `dev` actual aún no ofrece ayuda o validación local para los enums y sigue sin aplicar el fallback solicitado cuando la TTY devuelve ancho `0`; además, esos caminos no tienen cobertura de regresión.

## What This Changes

La issue solicita mejorar cuatro comportamientos de UX del CLI: detalle de validación, EPIPE silencioso, rechazo de token vacío y fallback de ancho de tabla.

## Best Possible Solution

Completar el CLI con tipos Clap que muestren y validen los valores canónicos, restaurar un fallback real a 80 solo para ancho `0` o desconocido y cubrir los cuatro comportamientos con pruebas focalizadas.
