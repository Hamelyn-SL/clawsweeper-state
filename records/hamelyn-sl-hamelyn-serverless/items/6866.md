## Summary

Gracias por el contexto: `dev` conserva tres correcciones de UX, pero los filtros siguen aceptando texto libre y no muestran ni validan localmente los valores permitidos.

## What This Changes

La incidencia pide mejorar la UX del CLI con detalles de validación, silencio ante EPIPE, rechazo de token vacío y un ancho de tabla seguro.

## Best Possible Solution

Añadir enums de Clap para los filtros documentados, conservar su serialización hacia la API y cubrir ayuda y rechazo local con `assert_cmd`.

## Solution Assessment
