## Label Justifications

- `P2`: Es una vulnerabilidad de severidad alta alcanzable mediante uploads de usuarios internos autorizados, sin evidencia actual de explotación, bypass o caída generalizada.
- `impact:security`: Un XLSX manipulado puede provocar contaminación de prototipos dentro del proceso Node de Admin.

## Summary

La issue sigue siendo necesaria: el `dev` actual mantiene `xlsx@0.18.5`, varias rutas de producción entregan ficheros subidos a `XLSX.read()` y no existe un PR abierto o merged que aplique la remediación. Comparte solución con https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7614, pero la política de este repositorio reserva el cierre automático a trabajo ya implementado.

## What This Changes

Actualizar las dependencias directas de `xlsx` a una distribución segura y validar las superficies de lectura y escritura XLSX de Admin/Core.

## Best Possible Solution

Resolver conjuntamente esta alerta y https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7614 mediante una versión única e inmutable de SheetJS `0.20.3` en Admin/Core, lockfile reproducible y pruebas reales de lectura y escritura XLSX sobre las rutas operativas.
