## Label Justifications

- `P2`: Es una vulnerabilidad alta y alcanzable mediante archivos externos, pero la entrada requiere un usuario autorizado y el alcance observado está acotado a los procesos XLSX.
- `impact:security`: Un archivo XLSX manipulado puede provocar contaminación de prototipos dentro de un proceso runtime de Admin.

## Summary

La issue sigue siendo necesaria: `dev` mantiene `xlsx@0.18.5`, una ruta autenticada de producción entrega bytes subidos directamente a `XLSX.read()` y no hay ningún PR abierto o merged que aplique la remediación. Comparte una única actualización operativa con https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7614, pero debe permanecer abierta hasta aprobar la fuente de suministro e implementar el cambio.

## What This Changes

Actualizar la dependencia runtime `xlsx` para eliminar la prototype pollution al leer archivos XLSX manipulados.

## Best Possible Solution

Resolver conjuntamente esta alerta y https://github.com/Hamelyn-SL/hamelyn-serverless/issues/7614 fijando el tarball oficial inmutable `xlsx@0.20.3` en Admin y Core, comprobando su integridad en el lockfile y validando los flujos reales de lectura y escritura antes de cerrar ambas issues.
