## Summary

La ruta actual convierte una clave `container_counter_M:<station>` ausente en `0`; la PR que introdujo multiestación documentó expresamente desplegar con el picking cerrado. Admitir un despliegue con picking abierto requiere decidir un contrato de migración compatible.

## What This Changes

Solicita mantener una numeración `M-` no colisionante al activar contadores multiestación durante un picking legacy ya abierto.

## Best Possible Solution

Definir una migración de activación atómica que reserve el siguiente bloque seguro por estación y conservar el reseteo a cero para pickings nuevos; si no se aprueba, reforzar el requisito de desplegar con el picking cerrado.
