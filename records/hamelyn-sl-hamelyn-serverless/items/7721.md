## Summary

Mantener abierta: `dev` aún convierte toda ausencia del snapshot eBay ES en `SYNC_ERROR/DB_ONLY` sin consultar la oferta viva, por lo que no resuelve los listings `PUBLISHED/ACTIVE` on-hold aportados.

## What This Changes

Distinguir en la reconciliación eBay ES los SKUs ausentes del snapshot que siguen vivos en Inventory API para evitar clasificarlos como `DB_ONLY` definitivo.

## Best Possible Solution

Validar cada candidato nuevo contra Inventory API con concurrencia y trazabilidad por SKU; conservar las ofertas vivas, separar el estado no publicable y tratar el `404` con la rama de recuperación aprobada.
