## Summary

Cerrar: la evidencia disponible apunta a una alerta mal interpretada, no a que el builder de CDL envíe precios válidos como `undefined`. En `dev`, el payload usa el precio de `mk_casaDelLibro` con fallback al stock maestro y falla antes del `POST /api/offers` si no hay precio; además, el triaje con datos vivos no encontró logs recientes de este error.

## What This Changes

El reporte pide revisar por qué Casa del Libro acumula `SYNC_ERROR / UPLOADING_ERROR` con `Price must be defined` pese a que los stocks maestros tienen precio positivo.

## Best Possible Solution

Cerrar este reporte y ajustar el heartbeat de Casa del Libro para medir nuevas transiciones al error o logs de `/api/cdl`, separando estado histórico `STALE` de actividad real.
