## Summary

Mantener abierto: el cierre forzoso puede seguir en curso tras su timeout y el PR libera el single-flight, permitiendo que una reconexión compita de nuevo con el teardown.

## What This Changes

El PR detecta reanudaciones de instancias Fluid, hace un ping Mongo single-flight de 3 s y recicla la conexión warm solo si ese ping expira.

## Best Possible Solution

Mantener la exclusión mutua hasta que el cierre real haya terminado, o introducir una transición explícita que impida conectar mientras siga pendiente, y cubrir el cierre que excede 5 s.
