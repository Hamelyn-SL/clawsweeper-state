## Summary

El PR sigue siendo necesario para la incidencia abierta de conexiones Mongo warm tras reanudar Fluid, pero no debe fusionarse aún: la única prueba publicada usa dobles de Mongo/Mongoose y no acredita el comportamiento en una instancia real con MongoDB.

## What This Changes

La rama detecta reanudaciones de instancias Fluid y aplica un ping Mongo single-flight de tres segundos, reciclando la conexión compartida solo si el ping expira.

## Best Possible Solution
