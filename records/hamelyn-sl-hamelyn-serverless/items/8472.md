## Summary

El parche aborda una regresión real de disponibilidad y no contiene un defecto funcional confirmado tras el arreglo de la carrera anterior. Debe seguir abierto: la evidencia visible es un harness con Mongoose y temporizadores simulados, no una ejecución contra MongoDB/Fluid reales.

## What This Changes

El PR detecta reanudaciones de instancias Fluid y ejecuta un ping Mongo single-flight de tres segundos, reciclando la conexión global solo cuando ese ping expira.

## Best Possible Solution

Validar en un entorno real y redactado una instancia suspendida con Mongo antes de mergear, comprobando tanto el ping normal tras reanudar como el reciclado tras un socket inválido.
