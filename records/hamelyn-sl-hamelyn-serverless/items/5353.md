Likely owner: JavierHamelyn

Options:

- **Definir severidad por ruta y fase (recommended):** Acordar en la incidencia compartida una respuesta estructurada y una política específica para `updatePrice` de eBay antes de modificar el handler.
- **Conservar HTTP 200 con métrica explícita:** Mantener compatibilidad HTTP y exponer `partial_failure`, contadores y severidad para alertado y BigQuery.
- **Elevar cualquier fallo parcial a error HTTP:** Devolver error para todo rechazo parcial, aceptando el impacto en los crons que continúan lotes con fallos permanentes.

## Solution Assessment

No del todo: el mapeo por `offerId` es una corrección útil, pero no resuelve la señal agregada del cron. La política debe acordarse antes de alterar el contrato HTTP compartido.
