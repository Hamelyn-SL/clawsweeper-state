## Summary

## What This Changes

El PR centraliza en la factory de ordersells la conversión de `shipPrice` a EUR, conserva `originalShipPrice` y elimina conversiones específicas de Amazon y ecommerce.

## Best Possible Solution

Mantener un único contrato: los formatters entregan el envío original y la factory lo convierte una sola vez, conservando el valor previo para facturación y consumidores históricos.
