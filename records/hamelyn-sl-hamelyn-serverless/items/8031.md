## Summary

Gracias por el contexto. La incidencia sigue siendo necesaria: el flujo actual imprime y avanza automáticamente, pero no valida la etiqueta física; faltan dos decisiones operativas que delimitan el comportamiento seguro.

## What This Changes

La incidencia solicita verificar mediante cámara/OCR o lectura de código que la última etiqueta de una cubeta de AutoPacking corresponde a esa cubeta.

## Best Possible Solution

Definir una primera versión que compare un identificador inequívoco de la etiqueta con el pedido activo, muestre una recuperación manual auditada y solo después integre la cámara o el escáner reutilizable.
