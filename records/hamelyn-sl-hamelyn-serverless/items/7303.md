## Summary

Debe seguir abierta: la ruta sigue dependiendo de `STOCK_KV_REST_API_URL` y `STOCK_KV_REST_API_TOKEN`, y la evidencia apunta a una corrección operativa pendiente en Vercel, no a algo ya implementado en `dev`.

## What This Changes

El informe pide corregir el fallo del cron diario `/api/notify-availability` cuando el proyecto `crons` no tiene configuradas las variables `STOCK_KV_REST_API_URL` y `STOCK_KV_REST_API_TOKEN`.

## Best Possible Solution

Mantener la ruta basada en KV y completar la configuración de Vercel para `crons` producción con las dos variables del KV de disponibilidad, seguido de un retry o verificación del siguiente run de `/api/notify-availability`.
