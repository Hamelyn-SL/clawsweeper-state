## Summary

La corrección sigue siendo necesaria en `dev`: el workflow aún agrupa las PR humanas por autor. La PR abierta https://github.com/Hamelyn-SL/hamelyn-serverless/pull/8189 concentra la solución y debe revisarse antes de integrar.

## What This Changes

La incidencia solicita que el recordatorio de PRs en Slack agrupe cada PR por la persona responsable de la siguiente acción.

## Best Possible Solution

Integrar, tras la revisión pendiente, una única derivación de `actionOwner` que cubra `REVISAR`, `CAMBIOS`, re-review y `MERGEAR` para todas las PR humanas.
