## Summary

El cambio sigue siendo necesario para el panel Bifrost, pero el beacon no refleja los cambios de pantalla en el momento prometido y la identidad del puesto puede falsificarse; además falta una prueba positiva del flujo autenticado.

## What This Changes

El PR añade un panel Bifrost en admin con presencia de puestos almacenada en Vercel KV, endpoints autenticados y un mapa de estaciones con acciones de conexión provisionales.

## Best Possible Solution

Vincular cada puesto a una credencial o identidad aprovisionada fuera de parámetros manipulables, observar la navegación real y aportar una ejecución autenticada y redactada del circuito completo.
